# T036 Evidence — explicit STM32 raw BIN import

## Status

`COMPLETE` on 2026-09-30 for the explicit device/base path. No inferred base
is applied. T037 owns vector-table candidates and confirmation; T038-T039 own
exact core/device-pack selection and catalog memory maps. All selected parts
retain catalog support state `PLANNED`.

## Implementation

- `Stm32CuratedPartIds` checks the SHA-256 of the pinned T032
  `selection.json` before exposing its 53 exact IDs. A family name, wildcard,
  unknown part, changed selection file, missing file, symlink, or oversized
  source cannot produce the verified selection token.
- Pure `Stm32RawBinPlan.explicit` requires that exact part, a caller-supplied
  32-bit base, and positive bounded length without address-space overflow.
  It offers no implicit default base or automatic inference.
- `Stm32RawBinImporter` maps into an already selected 32-bit little-endian ARM
  Ghidra program using the bundled native `BinaryLoader`. It rechecks pinned
  exact-part membership, provider length, language, native loader options,
  existing part provenance, and memory collision. An outer transaction rolls
  back on failure; successful imports record exact part, explicit base,
  length, and `EXPLICIT` base-selection provenance.

This provides byte mapping, not a verified per-part memory map, vector labels,
or proof that the selected Ghidra language matches the exact Cortex variant.
Those capabilities remain in T037-T041.
