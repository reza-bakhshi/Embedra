## Test-first evidence

The initial targeted test failed compilation with 43 absent production symbols.
It defined positive and negative contracts for descriptor metadata, resolved log
calls, exact FreeRTOS symbols, indexed function signatures, immutable inputs,
resource limits, and cancellation. Production implementation was then added.

## Implementation and verification

- Immutable facts distinguish strings, symbols, call sites, and function bytes.
  Mutable byte arrays and collections are defensively copied.
- IDF metadata is reported only from a parsed `esp_app_desc_t`. Context identity
  selects signatures but is not itself treated as detected metadata.
- Logging results require an exact supported target, resolved call, and constant
  tag/format pointers. Strings alone produce no result.
- FreeRTOS results require exact symbol facts and retain source-pack evidence.
- Signatures require exact device/IDF/toolchain/optimization indexing. Patterns
  shorter than eight bytes are rejected; full matches may be `VERIFIED`, while
  relocation-masked matches remain `DERIVED`.
- Reports list all detectors run and unavailable capabilities/indexes. Analysis
  has deterministic ordering, shared byte/object limits, and cancellation.
- The final clean run passed 122 unit and 17 real-Ghidra regression tests. Two
  complete builds produced byte-identical 440,492-byte extension ZIPs with
  SHA-256
  `07b9b8dfcc86223fd4dbbf1bed68f1091f11f5554b9c600e17ce8b229ef29aef`.
  The restricted dump and host paths are absent.

## Limitations

No bundled production library-signature payload, automatic Ghidra fact
collector, heap-object recovery, or desktop UI is claimed. T023 establishes the
pure evidence boundary; future inputs must have separately verified provenance.
Exact ESP part/package support remains unclaimed. T024 is the next task.
