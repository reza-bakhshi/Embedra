# T088 Evidence — Audit STM8 8-Bit MCU Family Capability Matrix & Catalog Specification

## Status

`COMPLETE` on 2026-10-13. T088 executes the comprehensive technical audit of the
STMicroelectronics STM8 8-bit MCU family across STM8S, STM8L, STM8A (STM8AF and
STM8AL), and STM8T lines against pinned ST reference manuals (RM0016 Rev 15, RM0031
Rev 15, PM0044/RM0013 Rev 5), datasheets, SPL headers, and license terms; records
a curated allowlist of 32 exact orderable silicon parts with explicit memory ranges
(Flash base `0x008000`, RAM base `0x000000`, EEPROM base `0x004000`, Option Bytes
base `0x004800`, Peripherals `0x005000`–`0x0057FF`, Boot ROM `0x006000`–`0x0067FF`),
peripheral complements, and package configurations initialized to `PLANNED`;
specifies the 32-slot interrupt vector table architecture at `0x008000` with 4-byte
`0x82` (`JPF`) entries; defines Ghidra language binding requirements with fail-closed
diagnostics; and establishes strict architectural isolation from 32-bit ARM Cortex-M
STM32 targets in accordance with `Embedra-SpecKit.md` (STM8-001 through STM8-010,
Section 8.2A, and Section 12).

## 3. Boundary & Invariant Summary

- **Families**: 4 (`STM8S`, `STM8L`, `STM8A` [STM8AF/STM8AL], `STM8T`).
- **Exact Parts**: 32 (14 STM8S, 8 STM8L, 7 STM8A, 3 STM8T).
- **Support State**: All 32 exact parts are `PLANNED` per STM8-010. Promotion to
  `EXPERIMENTAL` or `VERIFIED` requires subsequent implementation tasks (T089–T095).
- **Flash Origin**: Invariant `0x008000`.
- **Vector Table**: Invariant `0x008000`–`0x00807F`, 32 slots, 4-byte entries,
  opcode `0x82` + 24-bit jump target.
- **RAM Base**: Invariant `0x000000`.
- **EEPROM Base**: Invariant `0x004000`.
- **Peripherals Base**: Invariant `0x005000`–`0x0057FF` (page 0 MMIO).
- **STM32 Isolation**: Zero ARM Cortex-M, CMSIS, Thumb, or SVD assumptions.
