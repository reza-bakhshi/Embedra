2. Control/evidence tests failed compilation with 21 missing-symbol errors for confidence/evidence and stable diagnostic IDs.

The first implementation run also failed under compiler `-Werror` because a checked exception retained a non-serializable field; the diagnostic payload was made transient without disabling linting. The first complete quality run retained five Checkstyle failures and class-level branch-coverage failures. Formatting was corrected and boundary tests were added. A second complete run retained one 87% `SourceRange` branch result; below-range and non-contained-range tests raised it above the configured threshold.

## Implementation

- Added immutable checked half-open `SourceRange` and address-space-qualified `AddressRange` models with overflow detection.
- Added `BoundedLittleEndianReader` with unsigned 8/16/32-bit reads, 64-bit reads, bounded copying/skipping, cancellation checks, cursor preservation on failure, and typed limit/truncation diagnostics.
- Added thread-safe cooperative `CancellationSource`/`CancellationToken` and immutable configurable `ParserLimits`.
- Added stable diagnostic IDs, severities, optional source locations, and checked diagnostic failures shared by GUI/headless consumers.
- Added the exact confidence vocabulary and evidence categories required by the specification.
- Added `ProcessorNode` and validated `ExecutionTopology` models covering CPU/programmed/non-programmed node kinds, ISA and Ghidra language/compiler identity, role/ownership, reset entries, firmware source, security domains, shared memory/aliases, boot/reset relationships, mailboxes/FIFOs/semaphores/interrupts, symmetric or alternative-boot groups, confidence/evidence, and one-versus-separate-program strategy.
- Added defensive collection copies, unique-ID checks, dangling-reference rejection, and contradictory processor-metadata rejection.
- Documented defaults and invariants in `docs/architecture.md`, `README.md`, and ADR 0003.

## Limitations and Exact Resume Point

Range coordinates are non-negative signed `long` values and therefore stop at `Long.MAX_VALUE`; no current support claim requires a larger unsigned target address. `ParserLimits` defines immutable bounds, while cross-operation runtime accounting and adversarial enforcement remain assigned to T068. The topology records the program strategy but does not mutate or create Ghidra programs. No firmware format, target, catalog entry, or device was marked supported.

Begin T005 by reporting its deterministic schema/snapshot requirements. Write failing tests for canonical report ordering/schema identity, device-catalog snapshot/diff behavior, execution-topology reporting, and stable snapshot helpers before production implementation. Do not begin T006 until T005 is complete.
