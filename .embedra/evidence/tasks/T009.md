## Independent esptool observations

- Exit 2/rejected: truncated segment data and `0xffffffff` segment length.
- Exit 0 with warning: chip ID 0 when ESP32-S3 chip ID 9 was requested.
- Exit 0 with explicit invalid status: checksum and validation digest.
- Exit 0/display only: overlapping addresses, unaligned entry, and trailing data. These remain mandatory Embedra rejection cases; esptool success is not treated as acceptance.

Every esptool invocation used a ten-second timeout. No firmware was executed or flashed. Tool output was normalized only for trailing whitespace and repository paths before retention.
