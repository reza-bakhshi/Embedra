## Implementation

- Added a closed manifest schema v1 with stable URN, strict pack ID and numeric version, supported exact-device IDs, source/revision/license/transformation/redistribution provenance, content file sizes/digests, and aggregate descriptor digest.
- Added a dependency-free strict UTF-8 JSON parser with duplicate/unknown/type rejection, integral numbers, cancellation, and input/allocation/object/nesting/wall-time limits.
- Added deterministic canonical manifest output and stable pack diagnostics for invalid schema/provenance/path/integrity, install conflict/failure, not-found, and incompatible selection.
- Added streaming SHA-256 verification, checked aggregate size accounting, full declared-versus-actual tree comparison, and rejection of traversal, absolute/Windows paths, symlinks, special files, missing files, and unexpected files.
- Added local verify-copy-reverify installation with same-filesystem atomic publication and no overwrite of an exact installed version. Source directories remain unchanged; failures and cancellation do not publish a selectable pack.
- Added local-only selection with full re-verification, exact version/device constraints, and deterministic highest numeric compatible version. Corruption never falls back silently to another candidate.
- Added pack-format documentation and ADR 0005. SHA-256 is documented as corruption/integrity evidence, not publisher authentication.

## Limitations and Exact Resume Point

T006 installs already materialized local directories; it does not download or extract archives. It records redistribution disposition but does not authorize redistribution. SHA-256 detects changes relative to a manifest but does not authenticate a publisher; signing/trust roots require a later explicit contract. Filesystems without atomic directory moves receive `PACK_INSTALL_FAILED`. Broader archive and shared resource-budget adversarial enforcement remains T068, and the cross-package coverage review remains T070.
