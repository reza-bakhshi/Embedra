# T106 Evidence — Implement Pure Atmel / Microchip Target Providers, Catalog Registry & Memory Planners

## Status

`COMPLETE` on 2026-10-14. T106 implements pure Atmel / Microchip target providers, exact-part
catalog registry, and memory planners across 8-bit AVR microcontrollers (classic megaAVR,
classic tinyAVR, and modern AVR-Dx) and 32-bit ARM SAM microcontrollers (SAMD, SAME, SAMS,
SAMV, SAML, SAMC, SAM3) under shared `ParserLimits` and `CancellationToken`, strictly isolated
from other microcontroller families.
It enforces Harvard address space separation for 8-bit AVR (Flash `code`, SRAM `data`,
EEPROM `eeprom`, and I/O registers `io`), models the unified linear data alias window (`0x8000`)
for AVR-Dx devices, models 32-bit linear physical maps for SAM Cortex-M devices, and enforces
exact-part matching policies in accordance with `Embedra-SpecKit.md` (T106, ATMEL-001,
ATMEL-002, ATMEL-008, ATMEL-010, Section 8.3B, and Section 12).

## 1. Deliverables

1. **Domain Model & Catalog Entities**:
   - `io.github.rezabakhshi.embedra.targets.atmel.catalog.AtmelAddressModel`:
     - Enum representing address architecture (`HARVARD_SEPARATE`, `HARVARD_UNIFIED_DATA_ALIAS`, `LINEAR_32BIT`).
   - `io.github.rezabakhshi.embedra.targets.atmel.catalog.AtmelPartRecord`:
     - Immutable record capturing 27 exact silicon parts with memory sizes (Flash, SRAM, EEPROM),
       address models, vector counts, vector strides (2 vs 4 bytes), package codes, datasheets,
       and support states (`SupportState.PLANNED`).
     - Includes built-in standard factory templates (`defaultAtmega328p`, `defaultAtmega2560`,
       `defaultAttiny85`, `defaultAvr128da48`, `defaultSamd21g18a`, `defaultSame70q21`).

2. **Authoritative Catalog Registry**:
   - `io.github.rezabakhshi.embedra.targets.atmel.catalog.AtmelCatalogRegistry`:
     - Loads `catalogs/atmel/2026-10-14/catalog.json` with SHA-256 digest verification against `catalog.sha256`.
     - Supports cooperative cancellation via `CancellationToken` and respects `ParserLimits`.
     - Enforces strict exact-part matching policy (`getPart` / `findPart`), rejecting wildcards
       (`*`, `?`) and generic family prefixes (`AVR`, `ATMEL`, `ATmega`, `SAM`).

3. **Memory Planning Engine**:
   - `io.github.rezabakhshi.embedra.targets.atmel.memory.AtmelMemoryRegionKind`:
     - Region types: `CODE_FLASH`, `INTERNAL_SRAM`, `DATA_EEPROM`, `IO_REGISTERS`, `FLASH_DATA_ALIAS`,
       `PERIPHERALS_MMIO`, `FUSES`, `BOOT_ROM`.
   - `io.github.rezabakhshi.embedra.targets.atmel.memory.AtmelMemoryRegion`:
     - Immutable region representation with explicit `addressSpace` (`code`, `data`, `eeprom`, `io`, `default`),
       permissions (R/W/X), and volatility flags.
   - `io.github.rezabakhshi.embedra.targets.atmel.memory.AtmelMemoryPlan`:
     - Query interface: `isMapped(space, address)`, `isExecutable(space, address)`, `findRegion(space, address)`.
   - `io.github.rezabakhshi.embedra.targets.atmel.memory.AtmelMemoryPlanner`:
     - Synthesizes memory layouts:
       - Classic AVR: separate `code` (Flash), `data` (I/O registers + SRAM), `io` (direct 0x00..0x3F),
         `eeprom` (data EEPROM), and `FUSES`.
       - Modern AVR-Dx: `code` (Flash) and unified `data` space (MMIO at `0x0000`, EEPROM at `0x1400`,
         SRAM at `0x4000`, Flash Data Alias at `0x8000`).
       - SAM: 32-bit linear physical maps with Flash, SRAM, MMIO peripherals, and optional SAM-BA ROM.
     - Enforces non-overlap invariants within the same address space.

4. **Target Providers & Architecture Resolution**:
   - `io.github.rezabakhshi.embedra.targets.atmel.AtmelTargetProvider`: common interface.
   - `io.github.rezabakhshi.embedra.targets.atmel.AbstractAtmelTargetProvider`: abstract base class.
   - Concrete series providers:
     - `AtmegaTargetProvider` (`atmel-atmega`, `avr8:LE:16:default` / `avr8:LE:24:default`)
     - `AttinyTargetProvider` (`atmel-attiny`, `avr8:LE:16:default`)
     - `AvrDxTargetProvider` (`atmel-avr-dx`, `avr8:LE:24:xmega`)
     - `SamdTargetProvider` (`atmel-samd`, `ARM:LE:32:v6M` / `ARM:LE:32:v7EM`)
     - `SameTargetProvider` (`atmel-same`, `ARM:LE:32:v7EM` / `ARM:LE:32:v7M`)
   - `AtmelTargetProviders`: factory locator.
