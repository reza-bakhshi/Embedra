# T108 Evidence — Implement Atmel/Microchip ATDF / SVD Peripheral Packs, I/O Ports, Fuses & Schema Transforms

## Status

`COMPLETE` on 2026-10-16. T108 implements authoritative Atmel / Microchip peripheral register definition packs,
I/O port bitfield definitions, fuse bit maps, and schema transforms across 8-bit AVR microcontrollers
(classic megaAVR, classic tinyAVR, and modern AVR-Dx) and 32-bit ARM SAM microcontrollers (SAMD, SAME, SAMS, SAMV, SAM3)
under shared `ParserLimits` and `CancellationToken`, strictly isolated from other families.
The peripheral register packs enforce physical address space isolation (`DATA` for classic AVR I/O space and
`PERIPHERAL` for SAM 32-bit memory maps), non-overlapping bitfields, bounded resource limits, cooperative cancellation,
and cryptographic SHA-256 integrity verification against schema `"urn:embedra:schema:atmel-peripheral-pack:1"`
in accordance with `Embedra-SpecKit.md` (T108, ATMEL-005, ATMEL-008, ATMEL-009, Section 8.3B, and Section 12).

## 1. Deliverables

1. **Peripheral Pack Domain Model**:
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelBitField.java`:
     - Register bitfield record validating bit offsets (`0..31`), bit widths (`1..32`),
       positive masks, access modes, and single-bit factory helper.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelRegister.java`:
     - Register record supporting 8, 16, 24, 32, and 64-bit widths, absolute or struct-relative addressing,
       and bitfield lookup by name.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelPeripheral.java`:
     - Hardware peripheral block validating aperture bounds, address spaces (`DATA` vs `PERIPHERAL`),
       and register resolution by name and address.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelIoPort.java`:
     - Parallel I/O port mapping capturing port name, pin count, and data, direction, and input registers.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelFusePolarity.java`:
     - Enumeration modeling fuse polarity (`PROGRAMMED_LOW` where 0 = programmed, `PROGRAMMED_HIGH`).
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelFuseBit.java`:
     - Non-volatile configuration fuse bit model evaluating polarity and programmed status from raw byte values.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelFuseByte.java`:
     - Fuse byte or register definition with address, size, default value, and child fuse bits.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelFuseMap.java`:
     - Complete fuse bit map model capturing state (`PINNED`, `UNAVAILABLE`), reason, and byte lookups.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelInterrupt.java`:
     - Interrupt vector line model with index, canonical symbol name, and description.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelPeripheralPack.java`:
     - Immutable, verified bundle of peripherals, I/O ports, fuses, and interrupts for an Atmel part.

2. **Loader, Registry & Schema Transforms**:
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelPeripheralPackLoader.java`:
     - Strict bounded JSON loader with `ParserLimits`, `CancellationToken`, and SHA-256 integrity verification.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/atmel/peripheral/AtmelDevicePackRegistry.java`:
     - In-memory registry loading and indexing all 24 packs by part name and device alias with fallback lookups.

       I/O port summaries, decoded fuse byte comments, and interrupt table plates.
