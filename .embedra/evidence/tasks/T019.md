## Implementation

- `EspFlashRange` is a checked physical-storage type and cannot be confused with
  the existing CPU `AddressRange`.
- Discovery validates `0x8000` first, then scans sector-aligned candidates
  inside the bounded input. Explicit-offset parsing validates only that offset.
- Entries remain private until a well-formed MD5 marker and matching digest are
  present. Models defensively copy digest bytes and entry lists.
- Bounded UTF-8 labels, nonzero in-flash ranges, no table/partition overlap, no
  partition overlap, unique labels, object/input/allocation limits, and
  cancellation are enforced with stable diagnostic codes.
- Numeric custom type, subtype, full flags, encrypted bit, and read-only bit are
  preserved without assigning unsupported handler semantics.
