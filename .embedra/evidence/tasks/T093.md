# T093 Evidence — Wire STM8 Target Plans into Real-Ghidra GUI & Headless Multi-Program Import

## Status

`COMPLETE` on 2026-10-13. T093 completes real-Ghidra GUI and headless multi-program import support for
STMicroelectronics STM8 microcontrollers across raw BIN, Intel HEX, Motorola S-Record, and ELF formats
with language binding verification, transactional rollback on failure, user option persistence, and
headless parity in accordance with `Embedra-SpecKit.md` (T093, STM8-001, STM8-006, Section 8.2A, and Section 12).

## 1. Deliverables

1. **Multi-Format Input Decoding**:
   - `Stm8InputDecoder.java`: Validating decoder supporting raw BIN, Intel HEX, Motorola S-Record, and ELF.
     Enforces `ParserLimits`, strict checksum verification, overlapping record conflict detection,
     and fail-closed error handling under `Stm8MappingException` with `DiagnosticCode.STM8_FORMAT_UNSUPPORTED`.

2. **Ghidra Program Mapping & Transaction Management**:
   - `Stm8FirmwareMapper.java`: Maps physical STM8 memory blocks (`RAM` at `0x000000`, `DATA_EEPROM` at `0x004000`,
     `OPTION_BYTES` at `0x004800`, `PERIPHERALS` at `0x005000`, `BOOT_ROM` at `0x006000`, and `FLASH` at `0x008000`),
     vector table entry labels and entry points, peripheral plate comments, and register symbols within a safe
     `GhidraProgramTransaction` with complete rollback on mapping failure.
   - `Stm8MappingException.java`: Checked exception encapsulating `DiagnosticCode` for STM8 import failures.
   - `Stm8ImportReport.java`: Audit record of blocks created, vectors applied, and registers labeled.

3. **Orchestration Service & Ghidra Loader**:
   - `Stm8FirmwareImportService.java`: High-level service orchestrating catalog lookup, memory planning,
     vector table parsing, peripheral pack resolution, and program mapping.
   - `Stm8FirmwareLoader.java`: Ghidra loader extending `AbstractLibrarySupportLoader` registered as
     `"Embedra STM8 Firmware"`. Enforces language availability (`STM8:default:16:default` / `STM8:default:24:default`),
     exposes the `Target Silicon Part (optional override)` option, and executes transactional imports.

4. **Automated Test Suites**:
   - `src/test/java/io/github/rezabakhshi/embedra/ghidra/stm8/Stm8InputDecoderTest.java`:
     - Verifies correct decoding and entry-point resolution across all 4 formats for all 8 representative parts.
     - Verifies identical vector table byte extraction across all formats.
     - Verifies fail-closed validation on malformed checksums, truncated inputs, and overlapping data records.
