# T090 Evidence — Implement Pure STM8 Target Providers, Exact-Part Catalog Registry & Memory Planners

## Status

`COMPLETE` on 2026-10-13. T090 implements pure STM8 target providers, exact-part catalog
registry, and bounded memory planners (Flash base `0x008000`, RAM base `0x000000`,
EEPROM base `0x004000`, Option bytes base `0x004800`, Peripherals `0x005000`–`0x0057FF`,
Boot ROM `0x006000`–`0x0067FF`) under shared `ParserLimits` and `CancellationToken`,
strictly isolated from STM32 Cortex-M contracts in accordance with `Embedra-SpecKit.md`
(T090, STM8-001, STM8-003, STM8-006, STM8-007, STM8-010, Section 8.2A, and Section 12).

## 1. Deliverables

1. **Target Provider Hierarchy**:
   - `Stm8TargetProvider.java`: Pure interface defining STM8 capabilities (`providerId`,
     `family`, `selectLanguage`, `supports`, `planMemory`, `buildTopology`, `isAddressMapped`,
     `isValidCodeAddress`, `validateEntry`).
   - `AbstractStm8TargetProvider.java`: Common base class providing 8-bit CISC execution
     topology (`ProcessorKind.CPU_CORE`, `FirmwareSource.INDEPENDENT_IMAGE`, single program strategy),
     16-bit/24-bit adaptive Ghidra language selection (`STM8:default:16:default` vs `STM8:default:24:default`),
     24-bit linear address mapping classification, and entry point validation.
   - `Stm8sTargetProvider.java`: Mainstream STM8S family provider (RM0016).
   - `Stm8lTargetProvider.java`: Ultra-low-power STM8L family provider (RM0031).
   - `Stm8aTargetProvider.java`: Automotive STM8A (STM8AF/STM8AL) provider (RM0016 / RM0031).
   - `Stm8tTargetProvider.java`: Touch-sensing STM8T provider (RM0013 / DocID15655).
   - `Stm8TargetProviders.java`: Registry and factory with case-insensitive family and exact-part resolution.

2. **Exact-Part Catalog Registry**:
   - `Stm8PartRecord.java`: Immutable data model capturing exact orderable silicon part details
     (`exactPart`, `family`, `subfamily`, `packageType`, `flashBytes`, `ramBytes`, `eepromBytes`,
     `optionBytes`, `bootRomBytes`, `peripherals`, `supportState`, `datasheet`).
   - `Stm8CatalogRegistry.java`: Bounded catalog loader and registry indexing all 32 curated
     silicon parts from the authoritative catalog snapshot. Enforces exact part lookup with case
     insensitivity; explicitly rejects wildcards, regex tokens, and fuzzy queries per STM8-007;
     fails closed on missing parts with `DiagnosticCode.STM8_TARGET_UNSUPPORTED`.
   - `catalogs/stm8/2026-10-13/catalog.json` and `catalogs/stm8/2026-10-13/catalog.sha256`:
     Pinned offline catalog snapshot verified by SHA-256 integrity check.

3. **Memory Models & Layout Planner**:
   - `Stm8MemoryRegionKind.java`: Enumeration of STM8 regions (`RAM`, `EEPROM`, `OPTION_BYTES`,
     `PERIPHERALS`, `BOOT_ROM`, `FLASH`).
   - `Stm8MemoryRegion.java`: Immutable memory region with half-open bounds and permission semantics.
   - `Stm8MemoryPlan.java`: Validated memory plan enforcing non-overlapping physical regions,
     24-bit boundary validation, and Flash base anchor at `0x008000`.
   - `Stm8MemoryPlanner.java`: Pure deterministic planner constructing the 6 canonical regions
     from exact silicon records, validating boundary collision limits, and enforcing `ParserLimits`
     and `CancellationToken`.

4. **Strict Isolation from STM32 Cortex-M (STM8-001)**:
   - Zero dependencies or imports referencing `io.github.rezabakhshi.embedra.targets.stm32.*`,
     Cortex-M exception models, CMSIS, or SVD packs. Verified by reflection inspection tests.

5. **Diagnostic Codes**:
   - Extended `DiagnosticCode.java` with stable codes: `STM8_CATALOG_INVALID`,
     `STM8_CATALOG_INTEGRITY_MISMATCH`, `STM8_TARGET_UNSUPPORTED`, `STM8_MAPPING_CONFLICT`,
     `STM8_MAPPING_FAILED`, `STM8_ENTRY_REJECTED`, `STM8_LANGUAGE_MISMATCH`.

6. **Unit Test Suite**:
   - `Stm8TargetProviderTest.java`: 8 automated unit tests covering catalog loading, all 32 parts,
     wildcard rejection, all 4 family providers, memory layout correctness, 16/24-bit language
     adaptation, topology construction, entry-point validation, cancellation, and STM32 isolation.
