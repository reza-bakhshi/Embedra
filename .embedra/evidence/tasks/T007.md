## Implementation

- Added a `pureTest` mode that permits only `clean`/`pureTest` without Ghidra, excludes adapter sources, and runs the complete unit, architecture, Checkstyle, formatting, and coverage lifecycle. Other entry points retain early JDK/Ghidra compatibility failure.
- Added a separate `integrationTest` source set and `ghidraIntegrationTest` task compiled against the real pinned Ghidra API; configured `check` depends on it when Ghidra is present.
- Added `GhidraProgramTransaction`, which opens one named program transaction, rolls back on close by default, commits only after explicit request, rejects commit after close, and ends at most once.
- Added positive/negative fixture-provenance and handoff reconstruction validators and executable repository-policy tests.
- Added `.github/workflows/ci.yml` with read-only permissions, immutable action commits, JDK 21, a separate pure job, and a Ghidra/release job using the official 12.1.3 archive with published SHA-256 before integration, reproducibility, checksum, and artifact upload.
- Added fixture-policy documentation, architecture/README guidance, ADR 0006, and exact extension-content enforcement that excludes `.github` automation from the installable ZIP.
