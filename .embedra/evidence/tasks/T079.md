# T079 Evidence — Release Convergence, Quickstarts, and Complete Distribution Gate

## Status

`COMPLETE` on 2026-10-12. T079 validates release life-cycle operations (install,
uninstall, upgrade, clean-environment quickstarts, and agent-resume simulation)
on every claimed host platform (Linux x86-64, Ghidra 12.1.3 PUBLIC baseline),
produces the complete bit-for-bit reproducible release bundle, and verifies
full Spec Kit convergence across all 21 Constitutions, 9 User Stories, 27 ADRs,
device catalogs, and support claims.

## 1. Deliverables

- **Dedicated release lifecycle test & verification script**:
  - `scripts/verify-release-lifecycle.sh` (POSIX sh, fail-closed, automated):
    1. **Clean installation**: Unpacks the release extension ZIP into Ghidra's
       extensions directory structure; validates `Module.manifest` presence,
       `extension.properties` (`name=Embedra`, `version=12.1.3`, `author`),
       and core extension artifacts (`lib/Embedra.jar`, documentation, packs).
    2. **Clean uninstallation**: Removes the unpacked extension directory cleanly;
       verifies zero lingering configuration locks, leaked filesystem artifacts,
       or temp files.
    3. **Upgrade simulation**: Deploys an older simulated version (`0.9.0`) alongside
       active user project files (`user_project.gpr`, `user_notes.txt`); unzips
       the release extension over the installation; proves version metadata updates
       to `12.1.3` while preserving user workspace and project state bit-for-bit
       (asserted via SHA-256 digests).
    4. **Clean-environment quickstarts (`analyzeHeadless`)**:
       Configures an isolated sandbox (`XDG_CONFIG_HOME`, `XDG_CACHE_HOME`) with
       the extension cleanly installed; runs Ghidra headless analysis with Embedra
       loaders, analyzers, and a findings export post-script (`ExportEmbedraReport.java`)
       over 4 golden samples:
       - Raspberry Pi RP2040 UF2 (`rp2040-pico-blinky.uf2`): verified via
         `Embedra Raspberry Pi Firmware` loader; generated `rp2040-pico-blinky.uf2.report.json`.
       - ESP32-S3 full-flash dump (`default-factory.bin`): multi-program extraction
         (`factory` and `bootloader`) via `Embedra ESP Application Image` loader;
         generated `default-factory_factory.report.json`.
       - STM32 Intel HEX (`STM32F401RET6.hex`): verified via Cortex-M ARM loader
         and Embedra analyzers; generated `STM32F401RET6.hex.report.json`.
       - STM32 Raw BIN (`STM32F401RET6.bin`): verified via `BinaryLoader` with
         `-loader-baseAddr 08000000` and `ARM:LE:32:Cortex`; generated
         `STM32F401RET6.bin.report.json`.
       All generated JSON reports validated for schema integrity.
    5. **Agent-resume simulation**:
       Executes `sh scripts/validate-handoff.sh` and `sh scripts/validate-fixture-provenance.sh`
       to verify handoff continuity and fixture provenance across fresh agent runs.
- **Spec Kit convergence audit & test suite**:
  - `scripts/tests/test_release_lifecycle.py`:
    - Asserts presence and executability of `scripts/verify-release-lifecycle.sh`.
    - Asserts full presence of all 21 Constitutions (CORE-001 through CORE-021).
    - Asserts full presence of all User Stories (US1 through US9).
    - Asserts complete sequence of ADRs 0001 through 0027 in `docs/adr/`.
    - Asserts non-conflicting support claims, toolchain baselines (Ghidra 12.1.3,
      JDK 21), and host platform claims across `README.md`, `docs/compatibility-matrix.md`,
      `docs/support-matrix.md`, `Embedra-SpecKit.md`, and `.embedra/state.json`.
