# T109 Evidence — Real-Ghidra GUI & Headless Multi-Program Import Wiring for Atmel / Microchip

## Status

`COMPLETE` on 2026-10-16. T109 wires pure Atmel / Microchip target plans into the Ghidra import pipeline supporting
raw BIN, Intel HEX, and ELF formats across both GUI and headless environments. The import pipeline validates
both 8-bit AVR (`avr8:LE:16:default`, `avr8:LE:16:atmega256`, `avr8:LE:24:xmega`) and 32-bit ARM Cortex-M
(`ARM:LE:32:Cortex`, `ARM:LE:32:v6M`, `ARM:LE:32:v7EM`) language bindings. It enforces Harvard multi-address-space
mapping (`code` space with 16-bit word addressing for AVR flash, `mem` space for AVR SRAM/MMIO registers, and
32-bit linear address maps for SAM Cortex-M). It resolves composite multi-image layouts (standard application at
`0x00000000`, Optiboot bootloader at `0x00007E00` word `0x3F00`, and SAM-BA ROM bootloader at `0x00800000`).
Fail-closed validation strictly catches invalid vector opcodes, invalid initial stack pointers outside SRAM aperture,
truncated vector tables, truncated Intel HEX records, checksum mismatches, overlapping records, and truncated ELF
headers. Transactional mutations execute via `GhidraProgramTransaction` with complete rollback on cancellation
or failure, and 100% GUI and headless CLI parity is verified via `GhidraProgramEquivalenceAssertor` across
different locales and timezones in accordance with `Embedra-SpecKit.md` (T109, ATMEL-001 through ATMEL-010,
Section 8.3B, and Section 12).

## 1. Deliverables

1. **Ghidra Atmel Integration Components**:
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/atmel/AtmelMappingException.java`:
     - Checked exception carrying `DiagnosticCode` and `serialVersionUID` for Ghidra mapping failures.
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/atmel/AtmelImportReport.java`:
     - Immutable report record detailing import outcome, exact part, family, series, format, language ID,
       compiler spec, entry point, flash base, flash bytes, blocks created, and registers applied.
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/atmel/AtmelInputDecoder.java`:
     - Multi-format validating input decoder:
       - RAW_BINARY: Enforces Cortex-M vector table requirements (initial SP in SRAM `0x20000000..0x20500000`
         and odd Thumb reset vector) for SAM, and valid `RJMP` (0xC000) or `JMP` (0x940C) opcodes for AVR.
       - INTEL_HEX: Enforces record checksums, line lengths, non-overlapping segments, EOF termination,
         Optiboot detection (`0x7E00`), and SAM-BA detection (`0x00800000`).
       - ELF: Validates 32-bit little-endian ELF header, machines 83 (EM_AVR) and 40 (EM_ARM), program/section
         header bounds, and extracts PT_LOAD segments.
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/atmel/AtmelFirmwareMapper.java`:
     - Transactional mapper executing via `GhidraProgramTransaction`:
       - Language validation (`AVR8:*` or `ARM:LE:32:*`).
       - Initializes firmware segments and maps uninitialized target regions (`CODE_FLASH`, `INTERNAL_SRAM`,
         `IO_REGISTERS`, `EXTENDED_IO`, `DATA_EEPROM`, `PERIPHERALS_MMIO`, `SAM_BA_ROM`).
       - Labels primary entry points (`Reset_Handler`, `Optiboot_Reset_Handler`, `SAMBA_Reset_Handler`).
       - Labels interrupt vector table entries and slot comments.
       - Applies peripheral pack registers, I/O port summaries, and bitfield comments from `AtmelPeripheralPack`.
       - Records options under category `"Embedra Atmel Firmware"`.
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/atmel/AtmelFirmwareImportService.java`:
     - High-level import service resolving catalog parts, memory plans, and peripheral packs:
       - Single firmware image import (`importFirmware`).
       - Heuristic part resolution with exact part catalog override support.
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/atmel/AtmelFirmwareLoader.java`:
     - Ghidra loader entry point extending `AbstractLibrarySupportLoader`:
       - Declares loader name `"Embedra Atmel / Microchip Firmware"`.
       - Provides target silicon part option `Target Silicon Part (optional override)`.
       - Returns `avr8:LE:16:default` (or `avr8:LE:16:atmega256`) with compiler `gcc` for AVR,
         or `ARM:LE:32:Cortex` with compiler `default` for SAM.
       - Guarantees 100% parity between GUI and headless CLI execution.
