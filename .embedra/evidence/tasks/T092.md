# T092 Evidence — Implement STM8 Peripheral Register Data Packs, Bitfield Definitions & Schema Transforms

## Status

`COMPLETE` on 2026-10-13. T092 implements authoritative peripheral register definitions, bitfield models,
and schema transforms for STMicroelectronics STM8 microcontrollers (STM8S mainstream, STM8L ultra-low-power,
and STM8A automotive) in strict accordance with `Embedra-SpecKit.md` (T092, STM8-008, Section 8.2A, and Section 12).

## 1. Deliverables

1. **Immutable Core Models**:
   - `Stm8BitField.java`: Models an 8-bit register bitfield with strict 8-bit offset and width validation
     (`bitOffset in [0, 7]`, `bitWidth in [1, 8]`, `bitOffset + bitWidth <= 8`, exact mask verification).
   - `Stm8Register.java`: Models an 8-bit byte-wide hardware register located in STM8 MMIO space
     (`0x005000` to `0x0057FF`) with width validation (`widthBits == 8`), non-overlapping bitfields,
     and unique bitfield naming.
   - `Stm8Peripheral.java`: Models an STM8 peripheral block (e.g. GPIO, UART, SPI, I2C, TIM, ADC, FLASH)
     with physical bounds checking and collision validation.
   - `Stm8PeripheralPack.java`: Validated bundle of peripherals for a target family with schema verification.

2. **Ghidra Schema Transform**:
   - `Stm8PeripheralSchemaTransform.java`: Transforms peripheral definitions into standardized Ghidra
     plate comments and register EOL comments listing address, name, access mode, bitfields, and descriptions.

3. **Pack Loader & Registry**:
   - `Stm8PeripheralPackLoader.java`: Loads bounded JSON packs with SHA-256 integrity verification,
     enforcing `ParserLimits` and `CancellationToken`.
   - `Stm8DevicePackRegistry.java`: In-memory registry associating catalog parts with their respective
     peripheral definition packs for STM8S, STM8L, and STM8A.

4. **Redistributable Offline Packs**:
   - `catalogs/stm8/packs/stm8s-peripherals.json` & `.sha256`: Complete STM8S peripheral pack.
   - `catalogs/stm8/packs/stm8l-peripherals.json` & `.sha256`: Complete STM8L peripheral pack.
   - `catalogs/stm8/packs/stm8a-peripherals.json` & `.sha256`: Complete STM8A peripheral pack.

5. **Unit Verification Suite**:
   - `src/test/java/io/github/rezabakhshi/embedra/targets/stm8/Stm8PeripheralPackTest.java`:
     - Verifies loading and checksum validation for all 3 packs.
     - Verifies resolution for catalog parts.
     - Verifies byte-wide semantics, 8-bit widths, and exact bitfield masks across all peripherals.
     - Verifies plate and EOL schema comments.
     - Verifies fail-closed behavior on invalid bitfields or missing directories.
