# T097 Evidence — Build Independently Generated, Redistributable Nordic Fixtures and Oracles

## Status

`COMPLETE` on 2026-10-13. T097 builds independently generated, redistributable synthetic
Nordic Semiconductor firmware fixtures and official-tool oracles covering raw BIN,
Intel HEX, and ELF formats for representative parts across nRF51822, nRF52832, nRF52840,
nRF5340 (App and Net cores), and nRF9160 (Secure and Non-Secure domains); implements
SoftDevice combination images (S132 and S140) with MBR and application vector relocation
offsets (`0x00026000` and `0x00027000`); implements UICR configuration data blocks (`0x10001000`)
encoding bootloader address and customer data; implements dual-core nRF5340 and TrustZone
nRF9160 image pairs; and authors 5 negative malformed fixtures covering invalid Cortex-M
initial SP and even reset vectors, truncated HEX records, bad checksums, overlapping memory
ranges, and truncated ELF headers. All 19 fixtures are accompanied by manifests and oracles
satisfying `scripts/validate-fixture-provenance.sh` in accordance with `Embedra-SpecKit.md`
(T097, NRF-001, NRF-002, NRF-003, NRF-004, NRF-005, NRF-006, NRF-007, and Section 12).

## 1. Deliverables

1. **Deterministic Fixture Generator**:
   - `scripts/generate-nordic-fixtures.py`:
     - Synthesizes Cortex-M vector tables with valid SRAM initial SP and odd Thumb reset vectors.
     - Emits bit-exact Intel HEX with type 00 data records, type 04 extended linear addressing,
       and type 01 end-of-file records.
     - Emits standard 32-bit Little-Endian ARM ELF32 executables (EM_ARM = 40).
     - Assembles SoftDevice combination layouts (MBR at `0x00000000`, SoftDevice at `0x00001000`,
       application at `0x00026000` / `0x00027000`).
     - Emits UICR records with `BOOTLOADERADDR`, `NRFFW[0]`, and `CUSTOMER` registers.

2. **Valid Representative Part Fixtures (14 Fixtures)**:
   - Bare-metal application images (BIN, HEX, ELF):
     - `nrf51822_app.bin`, `nrf51822_app.hex`, `nrf51822_app.elf` (Cortex-M0, Initial SP `0x20004000`)
     - `nrf52832_app.bin`, `nrf52832_app.hex`, `nrf52832_app.elf` (Cortex-M4F, Initial SP `0x20010000`)
     - `nrf52840_app.bin`, `nrf52840_app.hex`, `nrf52840_app.elf` (Cortex-M4F, Initial SP `0x20040000`)
   - SoftDevice combination layouts (HEX):
     - `nrf52832_s132_app.hex` (MBR + S132 + App at `0x00026000`)
     - `nrf52840_s140_app.hex` (MBR + S140 + App at `0x00027000`)
   - UICR configuration data block (HEX):
     - `nrf52840_uicr.hex` (UICR at `0x10001000`, Bootloader `0x000F8000`, customer keys)
   - Dual-core nRF5340 image pairs (ELF):
     - `nrf5340_app_core.elf` (App core at `0x00000000`, Initial SP `0x20080000`)
     - `nrf5340_net_core.elf` (Net core at `0x01000000`, Initial SP `0x21010000`)
   - TrustZone nRF9160 image pairs (ELF):
     - `nrf9160_secure.elf` (Secure domain at `0x00000000`, Initial SP `0x20010000`)
     - `nrf9160_nonsecure.elf` (Non-Secure domain at `0x00040000`, Initial SP `0x20040000`)

3. **Malformed Negative Fixtures (5 Fixtures under `nordic/malformed/`)**:
   - `nrf52_invalid_vector.bin`: Initial SP pointing to FICR aperture (`0x10000000`) and even reset vector (`0x00000100`, missing Thumb bit).
   - `nrf52_truncated.hex`: Intel HEX truncated in mid-record.
   - `nrf52_bad_checksum.hex`: Intel HEX record with corrupted checksum byte.
   - `nrf52_overlapping.hex`: Intel HEX with conflicting overlapping addresses at `0x00000000`.
   - `nrf52_truncated_elf.elf`: ELF file truncated before section header table.

4. **Manifests and Oracles**:
   - 19 fixture manifests under `src/test/resources/fixtures/nordic/` and `malformed/` conforming
     to `scripts/validate-fixture-provenance.sh` (`redistributionStatus = "REDISTRIBUTABLE"`).
   - 13 oracle JSON snapshots under `src/test/resources/oracles/nordic/` and `malformed/`.

5. **Automated Verification**:
