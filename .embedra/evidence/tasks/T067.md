# T067 Evidence — Fixture Manifests, Deterministic Generators, Private-Fixture Handling, and Requirement-to-Evidence Indexing

## Status

`COMPLETE` on 2026-10-10. T067 implements closed fixture manifest schemas, deterministic generation runners, private-fixture isolation and validation, and requirement-to-evidence indexing with full pure domain separation and branch coverage verification:

- **JSON Schemas**:
  - `schemas/fixture/fixture-manifest-v1.schema.json`: Closed schema (`$id: urn:embedra:schema:fixture-manifest:1`, `additionalProperties: false`) defining all 17 fixture manifest fields across existing and planned fixtures (target, format, provenance, licensing, redistribution, tools, oracles, expected snapshots, requirements).
  - `schemas/evidence/evidence-index-v1.schema.json`: Closed schema (`$id: urn:embedra:schema:evidence-index:1`, `additionalProperties: false`) defining canonical requirement-to-evidence indexing.
  - Registered and validated in `SchemaResourcesTest`.

- **Diagnostics** (`io.github.rezabakhshi.embedra.core.diagnostic.DiagnosticCode`):
  - Added `FIXTURE_MANIFEST_INVALID`, `FIXTURE_SCHEMA_UNSUPPORTED`, `FIXTURE_INTEGRITY_MISMATCH`, `FIXTURE_PATH_UNSAFE`, `FIXTURE_REDISTRIBUTION_INVALID`, `EVIDENCE_INDEX_INVALID`, `EVIDENCE_INDEX_SCHEMA_UNSUPPORTED`.

- **Pure Fixture Domain** (`io.github.rezabakhshi.embedra.core.fixture`):
  - `RedistributionStatus`: Enum (`REDISTRIBUTABLE`, `RESTRICTED_LOCAL`, `PROPRIETARY_PRIVATE`) with classification queries and case-insensitive parsing.
  - `FixtureManifestJsonParser`: Bounded JSON parser respecting `ParserLimits` (max bytes, max objects, max depth, wall time) and `CancellationToken`.
  - `FixtureManifest`: Immutable record representing fixture metadata, validating non-blank IDs, lowercase 64-hex SHA-256, path safety (rejection of `..` traversal), binary payload integrity validation against file on disk (`validateFixtureBinary`), and canonical JSON export (`toJson()`).
  - `DeterministicFixtureGenerator`: Public SPI interface for deterministic fixture synthesis (`generatorId()`, `generate(Map<String, Object>)`).
  - `DeterministicGenerationRunner`: Runs generators in two isolated environments, verifies byte-for-byte identity (`Arrays.equals`), and includes 3 built-in generators (`armVectorGenerator()`, `riscvVectorGenerator()`, `flashPartitionGenerator()`).
  - `PrivateFixtureManager`: Manages private firmware fixtures (including the T021 4 MiB ESP32-S3 flash dump `837ee155de84403f84330179d52edfd2dba239cc11af5e55c2d0c28bc38a71de`), resolves locations via `embedra.private.fixtures.dir` property/env/fallback, enforces zero private fixtures inside `src/test/resources/fixtures/`, rejects symlinks, verifies SHA-256 digests, and returns `Optional.empty()` when missing so public CI suites never fail.

- **Pure Evidence Index Domain** (`io.github.rezabakhshi.embedra.core.evidence`):
  - `EvidenceResultStatus`: Enum (`PASS`, `FAIL`, `SKIPPED`).
  - `EvidenceIndexEntry`: Immutable record tying requirement ID, task ID, test class/method, fixture ID, result status, retained artifacts, and verification notes.
  - `EvidenceIndex`: Canonical index document adhering to schema `urn:embedra:schema:evidence-index:1`, with sorting, bounded JSON parsing, JSON serialization, and queries: `findEntriesForRequirement()`, `findEntriesForTask()`, `findEntriesForFixture()`, `allCoveredRequirements()`, and `allCoveredTasks()`.
  - `EvidenceIndexGenerator`: Scans `.embedra/evidence/tasks/*.md`, `src/test/resources/fixtures/**/*.manifest.json`, and explicit test bindings to generate machine-readable `.embedra/evidence/evidence-index.json`.
