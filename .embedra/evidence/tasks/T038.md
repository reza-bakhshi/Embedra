# T038 Evidence — STM32 exact-part catalog registry

## Status

`COMPLETE` on 2026-09-30 for catalog-backed exact-part search and selection.
The 53 records remain `PLANNED` for device support. T039 owns memory maps and
execution topology; T040-T041 own SVD data and interrupt/vector enrichment.

## Implementation

- `Stm32DevicePackRegistry` loads the pinned 53-record curated catalog only
  with the digest-verified T032 selection token. It checks the catalog SHA-256,
  schema, linked selection digest, cardinality, unique exact IDs, and planned
  support state before exposing immutable descriptors.
- Descriptors keep exact part, family, line, package, optional flash/RAM sizes,
  unresolved flash alternatives, processor core/index/role, lifecycle,
  marketing state, source reference, and catalog digest separate. Lifecycle
  remains `UNKNOWN` even when marketing status was `ACTIVE` at selection.
- Case-insensitive search returns sorted candidates and explicit `NO_MATCH`,
  `SINGLE_CANDIDATE`, `AMBIGUOUS`, or `EXACT_ID` status. Only case-sensitive
  exact-ID selection returns a selected descriptor. Family names, partial
  names, wildcards, and lowercased IDs cannot be selected implicitly.
- Every registry entry is `CATALOG_ONLY`; no memory/SVD/interrupt device pack
  or exact core-language proof is claimed. The registry can supply exact-part
  membership to the T036 raw BIN plan.
