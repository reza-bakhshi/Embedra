# T051 Evidence — UF2 validation/reconstruction, raw XIP/internal-flash import, and boot metadata

## Status

`COMPLETE` on 2026-10-03. T051 implements target-address UF2 validation and reconstruction,
variant-aware raw XIP / internal-flash boot metadata parsing (RP2040 boot2 CRC, RP2350/RP2354 IMAGE_DEF),
and transactional Ghidra firmware loader support (`RpFirmwareLoader`, `RpFirmwareMapper`) covering RP2040,
RP2350 ARM, RP2350 RISC-V, and RP2354 stacked flash without mutating earlier task artifacts or promoting
device support states (`PLANNED` per RP-002 and STM-019).

and 110 real-Ghidra integration tests (6 new integration tests in `RpFirmwareLoaderTest`).

The reproducible completion gate passes with two clean, uncached 22-action builds and a byte-identical

## Scope and invariants

- Pure/adapter boundary:
  - Pure packages: `io.github.rezabakhshi.embedra.formats.rp.uf2` and `io.github.rezabakhshi.embedra.targets.rp.boot`.
    No Ghidra APIs or adapter references are imported in pure code.
  - Ghidra adapter: `io.github.rezabakhshi.embedra.ghidra.rp` (`RpFirmwareLoader`, `RpFirmwareImportService`,
    `RpFirmwareMapper`, `RpImportReport`, `RpMappingException`).
- Target address reconstruction (RP-001):
  - `RpUf2Reconstructor` sorts blocks strictly by target CPU address, coalescing contiguous blocks into
    `RpUf2Segment`s and handling out-of-order blocks, sparse gaps, and multi-family payloads.
  - Never loads UF2 file offsets directly as memory addresses.
- Variant-aware boot metadata parsing:
  - `RpBootMetadataParser`:
    - RP2040: calculates CRC-32 (polynomial `0x04C11DB7`, initial `0xFFFFFFFF`, final XOR `0`, unreflected)
      across the 256-byte boot2 preamble, validates vector table entries (initial SP in SRAM `0x20000000..0x20042000`,
      reset vector in flash XIP `0x10000000..0x12000000`), and determines external flash entry points.
    - RP2350/RP2354: parses IMAGE_DEF block (`0xffffded3` magic), architecture tags (ARM vs RISC-V),
      security domains (Secure vs Non-Secure), block items, vector/trap table offsets, and internal stacked 2 MiB flash.
- Ghidra integration:
  - `RpFirmwareLoader`: detects UF2 containers and raw RP binaries, offering exact installed Ghidra languages:
    `ARM:LE:32:Cortex` (RP2040), `ARM:LE:32:v8-m` (RP2350 ARM), and `RISCV:LE:32:default` with `gcc` (RP2350 RISC-V).
  - `RpFirmwareMapper`: performs preflight validation before opening a `GhidraProgramTransaction`.
    Maps memory blocks at target CPU addresses, sets entry points, labels vector tables, records diagnostic
    bookmarks and program options, and guarantees clean rollback on failure or cancellation.
- All 5 cataloged RP silicon records and 4 board profiles retain `PLANNED` state (RP-002, STM-019).
