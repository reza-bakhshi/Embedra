# T098 Evidence — Nordic Target Providers, Exact-Part Catalog Registry & Memory Planners

## Status

`COMPLETE` on 2026-10-13. T098 implements pure Nordic Semiconductor target providers,
an exact-part catalog registry, and memory planners for nRF51 (Cortex-M0), nRF52 (Cortex-M4/M4F),
nRF53 (dual Cortex-M33 App + Net), nRF54 (Cortex-M33/RISC-V), and nRF91 (Cortex-M33 LTE-M /
NB-IoT / TrustZone) series under shared `ParserLimits` and `CancellationToken`. The
catalog registry loads and validates the official dated snapshot `catalogs/nordic/2026-10-13/catalog.json`
against its SHA-256 checksum, enforcing strict exact-part lookups and rejecting fuzzy
matching, wildcards, and bare family prefixes per NRF-010. Memory planners synthesize
non-overlapping physical memory layouts covering Code Flash (`0x00000000`), SRAM (`0x20000000`),
FICR (`0x10000000` / `0x00FF0000`), UICR (`0x10001000` / `0x00FF8000`), APB/AHB MMIO peripherals
(`0x40000000` / `0x50000000`), CryptoCell hardware apertures (`0x5002A000` CC310 / `0x50840000` CC312),
and dual-core network partitions in accordance with `Embedra-SpecKit.md` (T098, NRF-001 through NRF-010,
Section 8.3A, and Section 12).

## 1. Deliverables

1. **Catalog Domain Model & Registry**:
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/catalog/NordicPartRecord.java`:
     - Immutable record capturing exact part number, series, subfamily, package code,
       core architecture, FPU presence, flash and RAM byte sizes, FICR and UICR ranges,
       peripheral ranges, CryptoCell engine metadata, TrustZone and dual-core flags,
       support state, and reference datasheet.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/catalog/NordicCatalogRegistry.java`:
     - Thread-safe, fail-closed catalog registry loading and validating dated catalog
       snapshots.
     - Verifies SHA-256 checksum against `catalog.sha256`.
     - Uses `StrictJsonParser` under bounded `ParserLimits` and cooperative `CancellationToken`.
     - Enforces case-insensitive exact part lookup (`findExactPart`), rejecting wildcards,
       partial matches, and bare series prefixes.

2. **Memory Planning Domain Model & Planner**:
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/memory/NordicMemoryRegionKind.java`:
     - Enum representing physical memory kinds (`FLASH`, `RAM`, `FICR`, `UICR`, `PERIPHERALS`, `CRYPTOCELL`, `NETWORK_FLASH`, `NETWORK_RAM`).
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/memory/NordicMemoryRegion.java`:
     - Checked address range with permission flags (`readable`, `writable`, `executable`) and evidence tracking.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/memory/NordicMemoryPlan.java`:
     - Immutable, non-overlapping memory plan binding regions to a specific `NordicPartRecord`.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/memory/NordicMemoryPlanner.java`:
     - Synthesizes verified physical memory layouts according to series invariants, ensuring no
       overlapping regions and accurate permission bits.

3. **Pure Target Providers**:
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/NordicTargetProvider.java`:
     - Interface declaring series identity, Ghidra language selection, support decisions,
       memory planning, entry point validation, and topology construction.
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/AbstractNordicTargetProvider.java`:
     - Common base implementation providing Thumb entry point validation, memory mapping queries,
       and `ExecutionTopology` construction (`ProcessorNode` with verified reset handlers).
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/Nrf51TargetProvider.java`:
     - Target provider for nRF51 series selecting `ARM:LE:32:v6M` (ARM Cortex-M0).
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/Nrf52TargetProvider.java`:
     - Target provider for nRF52 series selecting `ARM:LE:32:v7EM` (ARM Cortex-M4/M4F).
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/Nrf53TargetProvider.java`:
     - Target provider for nRF53 series selecting `ARM:LE:32:v8M` (ARM Cortex-M33 dual-core).
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/Nrf54TargetProvider.java`:
     - Target provider for nRF54 series selecting `ARM:LE:32:v8M` (ARM Cortex-M33).
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/Nrf91TargetProvider.java`:
     - Target provider for nRF91 series selecting `ARM:LE:32:v8M` (ARM Cortex-M33 TrustZone).
   - `src/main/java/io/github/rezabakhshi/embedra/targets/nordic/NordicTargetProviders.java`:
     - Static registry providing lookup by provider ID, series, or part record.
