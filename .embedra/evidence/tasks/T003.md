- Declared `core`, `formats`, `targets`, `analyzers`, and `pack` pure with respect to Ghidra APIs and the Embedra Ghidra adapter package.
- Reserved `ghidra` for loaders, mappers, services, UI, and transactional application of validated pure models.
- Added a recursive source architecture test that reports repository-relative file and line evidence for forbidden imports or known qualified Ghidra API references.
- Added a negative fixture so a disabled or inert detector cannot silently pass.
- Documented the dependency direction in `docs/architecture.md` and ADR 0002.
- Extended exact package validation to require the architecture document and validate the nested production source ZIP.
