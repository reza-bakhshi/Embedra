## Test-first evidence and implementation

The first targeted test failed compilation with 36 absent production symbols.
The implementation compares retained SHA-256 and physical flash ranges to
classify unchanged, moved, modified, added, and removed artifacts. Findings are
limited to numeric secure-version rollback, a verified candidate digest
mismatch, and an unencrypted NVS-key partition. Arbitrary version strings do not
produce rollback findings. Results have stable codes, confidence, evidence,
deterministic order, source ranges where available, and secret-export marking;
NVS-key bytes are never retained. Shared limits, cancellation, and immutable
collections are tested.

The clean gate run passed 128 unit and 17 real-Ghidra tests. Two builds produced
an identical 478,775-byte ZIP with SHA-256
`df78f9c8cf51cb5fec7531ec88f299aca01aa01077d11e53f9e5397ffa311faf`.

## Limitations

flag, crypto, entropy, function, string, and memory diffing remain T056-T064.

acceptance gate.
