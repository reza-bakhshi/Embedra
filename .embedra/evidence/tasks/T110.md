# T110 Evidence — AVR & SAM Common Runtime Signatures & CTF Enrichment

## Status

`COMPLETE` on 2026-10-16. T110 implements AVR and SAM common runtime signatures (Arduino core libraries,
AVR-libc, Atmel START / ASF, FreeRTOS) and CTF/string/lead enrichment using shared analyzers in accordance
with `Embedra-SpecKit.md` (T110, Section 8.3B, and Section 12).

## 1. Deliverables

1. **Shared Core Analyzer Extensions**:
   - `InstructionArch.java`: Added `AVR8` instruction architecture targeting stack string recovery and security leads.
   - `StackInstruction.java`: Added `avr8` instruction factory method.
   - `StackStringRecoveryAnalyzer.java`: Implemented AVR8 stack-constructed string recovery (`ldi`, `mov`, `movw`, `push`, `std Y+q`, `st Y`).
   - `ComparisonLeadScanner.java`: Added AVR8 call instructions (`call`, `rcall`, `icall`), argument mapping (`r24`, `r22`, `r20`, `r18`), and branch patterns (`breq`, `brne`, `brcs`, `brcc`, `brmi`, `brpl`).
   - `CallSiteArgumentResolver.java`: Added AVR8 calling convention argument tracking and termination instructions.
   - `AssertPanicPatternMatcher.java`: Added AVR8 (`break`, `sleep`, `rjmp .`) and STM8 termination patterns.
   - `EmbedraCtfAnalyzer.java`, `EmbedraStringAnalyzer.java`, `EmbedraSecurityLeadAnalyzer.java`, `EmbedraLoggingAnalyzer.java`: Added AVR8 architecture detection.

2. **Pure Atmel / Microchip Runtime Signature Engine**:
   - `AtmelFunctionBytes.java`: Address and function machine code container.
   - `AtmelLibrarySignature.java`: Masked byte-pattern signature model with defensive cloning, fully specified mask reporting, and SHA-256 provenance tracking.
   - `AtmelSignatureContext.java`: Exact part, series, architecture, compiler, optimization, and scanned function context.
   - `AtmelSignatureMatch.java` & `AtmelSignatureNonMatch.java`: Match and non-match audit records.
   - `AtmelSignatureMatchReport.java`: Aggregated signature scan report.
   - `AtmelSignaturePack.java`: Curated built-in signature pack containing:
     - Arduino Core (AVR8): `init`, `pinMode`, `digitalWrite`, `digitalRead`, `delay`, `millis`, `HardwareSerial::begin`.
     - AVR-libc (AVR8): `__do_copy_data`, `__do_clear_bss`, `malloc`, `free`, `__bad_interrupt`.
     - Atmel START / ASF (SAM Cortex-M): `system_init`, `delay_ms`, `usart_sync_enable`, `gpio_set_pin_level`.
     - FreeRTOS (SAM & AVR8): `vTaskStartScheduler`, `xTaskCreate`, `vTaskDelay`, `xQueueGenericCreate`.
   - `AtmelSignatureMatcher.java`: Pure bounded matcher enforcing evidence gating under `ParserLimits` and `CancellationToken`.

3. **CTF, String & Security Lead Pipeline**:
   - `AtmelCtfEnrichmentContext.java`: Memory bytes, functions, and symbols container.
   - `AtmelCtfEnrichmentReport.java`: Deterministic analysis results.
   - `AtmelCtfEnrichmentAnalyzer.java`: Pure pipeline executing signature matching, multi-encoding string scanning, stack string recovery (AVR8 & ARM Thumb), CTF entity discovery (flags, URLs, credentials), and command table discovery (16-bit for AVR, 32-bit for SAM).

4. **Ghidra Analyzer Pipeline**:
   - `EmbedraAtmelSignatureAnalyzer.java`: Ghidra `AbstractAnalyzer` registering as `"Embedra Atmel / Microchip Signatures"` under `FUNCTION_ANALYSIS.after()`, labeling matched functions, setting PLATE/EOL comments, and tagging signature bookmarks.

5. **Automated Unit & Integration Tests**:
   - `AtmelLibrarySignatureTest.java`: Pattern masking, defensive copy immutability, validation constraints.
   - `AtmelSignatureMatcherTest.java`: AVR and SAM runtime matches, evidence gating, resource limits, and cancellation.
   - `AtmelCtfEnrichmentAnalyzerTest.java`: Full pipeline test verifying signatures, static string extraction, flag/URL CTF discovery, and stack string recovery on AVR8 and SAM firmware.
   - `EmbedraAtmelSignatureAnalyzerTest.java`: Ghidra analyzer metadata, priority, enablement, and null safety.
