# T050 Evidence — Raspberry Pi silicon/board catalog and fixtures

## Status

`COMPLETE` on 2026-10-02. T050 builds the authoritative Raspberry Pi silicon and board catalog,
pure target providers, UF2 container parser, and deterministic golden fixtures covering RP2040,
RP2350A/B, RP2354A/B, UF2, raw BIN, ELF, external/internal flash, both CPU cores, ARM/RISC-V,
TrustZone, TinyUSB, Pico/Pico W/Pico 2/Pico 2 W, and PIO without mutating existing evidence.

All newly cataloged Raspberry Pi silicon parts and board profiles start in the `PLANNED` state
per RP-002 and STM-019. The 53 curated STM32 parts, ESP catalog, memory plans, and earlier
artifacts remain completely untouched and unmutated.

The repository builds 416 unit tests (38 new T050 tests across catalog, providers, UF2 parser,
and fixture assertions) and 104 real-Ghidra integration tests. The Python suites report 131
STM32 tests (`OK (skipped=4)`), 4 ESP catalog tests, and 8 RP catalog/fixture tests.
The reproducible completion gate passes with two clean, uncached 22-action builds and a
byte-identical extension ZIP, SHA-256 `acee51444ae4ea479929c5758d0e411dcbe4750e4b356c8df5b0cc676b945441`
(4,575,353 bytes).

## Scope and invariants

- The pure/adapter boundary holds. All T050 classes live under `targets.rp` and `formats.rp.uf2`;
  they import `core`, `targets`, and `formats` model classes only and never import Ghidra APIs.
  No Ghidra mutation exists in this task (`NO_ADAPTER_PURE_PLAN_ONLY`).
- RP-002 / STM-019: Every cataloged part begins in `PLANNED` state. No capability or device
  verification is claimed from sibling parts or catalog entry presence alone.
- Authoritative offline catalog: `catalogs/rp/2026-10-02/catalog.json` and `board-profiles.json`
  generated deterministically by `scripts/generate-rp-catalog.py`. Validated against closed schemas
  `urn:embedra:schema:rp-catalog:1` and `urn:embedra:schema:rp-board-profiles:1` with pinned SHA-256
  checksum files (`catalog.sha256`, `board-profiles.sha256`).
- Exact silicon records:
  - `RP2040`: dual Cortex-M0+ ARMv6-M @ 133MHz, 264 KiB multi-bank SRAM, external QSPI flash XIP
    (0x10000000), SIO inter-core FIFO (0xD0000050) and 32 spinlocks (0xD0000100), 2 PIO blocks (8 SMs).
  - `RP2350A` / `RP2350B`: dual Cortex-M33 ARMv8-M mainline with TrustZone or dual Hazard3 RV32IMAC
    RISC-V @ 150MHz, 520 KiB multi-bank SRAM, OTP memory (0x40130000, 8 KiB), 3 PIO blocks (12 SMs),
    QMI XIP up to 16 MiB.
  - `RP2354A` / `RP2354B`: stacked 2 MiB internal QSPI flash (`INTERNAL_FLASH` memory region),
    dual Cortex-M33 / Hazard3 RISC-V cores.
- Board profiles:
  - `pico`: Raspberry Pi Pico (RP2040, 2 MiB flash, GPIO 25 LED).
  - `pico_w`: Raspberry Pi Pico W (RP2040, 2 MiB flash, Infineon CYW43439 wireless).
  - `pico2`: Raspberry Pi Pico 2 (RP2350A, 4 MiB flash, GPIO 25 LED).
  - `pico2_w`: Raspberry Pi Pico 2 W (RP2350A, 4 MiB flash, CYW43439 wireless).
- UF2 Container format: `io.github.rezabakhshi.embedra.formats.rp.uf2` provides bounded parsing
  (`RpUf2Parser`), model (`RpUf2Block`, `RpUf2Image`, `RpUf2Family`), and continuous binary
  extraction. Enforces 512-byte block size, start/end magic numbers, payload bounds, block sequence,
  and recognized family IDs (`0xe48bff56` RP2040, `0xe48bff57` RP2350 ARM Secure, `0xe48bff58`
  RP2350 RISC-V, `0xe48bff59` RP2350 ARM Non-Secure).
- Deterministic fixture generation: `scripts/generate-rp-fixtures.py` builds twice in temporary
  directories, verifying byte-reproducibility across runs. Toolchains used: `arm-none-eabi-gcc` 13.2.1
  and `riscv32-esp-elf-gcc` 15.2.0.
  - Generated fixtures in `src/test/resources/fixtures/rp/`:
    - `rp2040-freestanding-dualcore.elf`: dual-core Cortex-M0+, boot2, vector table, TinyUSB symbols, PIO0.
    - `rp2040-boot2-xip.bin`: 256-byte boot2 preamble.
    - `rp2040-pico-blinky.uf2`: UF2 image targeting 0x10000000.
    - `rp2350-arm-trustzone.elf`: Cortex-M33 TrustZone Secure image, Image Def Block (0xffffded3), NSC veneer.
    - `rp2350-arm-pico2.uf2`: ARM Secure UF2 image.
    - `rp2350-riscv-trap.elf`: Hazard3 RV32IMAC image, Image Def Block, machine trap handling, PIO.
    - `rp2350-riscv-pico2.uf2`: RISC-V UF2 image.
    - `rp2354-stacked-flash.bin`: stacked internal 2 MiB flash raw binary.
    - `malformed/uf2-corrupted-magic.uf2`: invalid magic start.
    - `malformed/uf2-truncated-block.uf2`: truncated block length.
    - `malformed/uf2-family-mismatch.uf2`: unrecognized family ID.
  - Every fixture possesses a matching `.manifest.json` satisfying `scripts/validate-fixture-provenance.sh`.
  - Every fixture has a matching expectation snapshot in `src/test/resources/oracles/rp/`.
