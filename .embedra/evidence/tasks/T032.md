## Status

`IN_PROGRESS` on 2026-09-28. The acceptance boundary is defined in ADR 0026.
No T032 completion or STM32 firmware support claim is made.

- Pinned ST `STM32_open_pin_data` BSD-3-Clause revision
  `7d1f1514ed5583ec5007ad91236b4e1d377295b1`.
- Deterministic, offline, derived source-facts snapshot: 2,240 MCU/MPU ST

  interrupt vectors, and CMSIS-SVD transformation mappings. These block T032.

## CMSIS source reconciliation checkpoint

27 ST CMSIS Device repositories were pinned at exact Git revisions and checked
for Apache-2.0 licenses. A bounded generator indexed 377 IRQ-bearing headers
with per-header SHA-256 and core suffixes. Of 2,240 ST references, 1,906 map
to one nonconditional header, 164 to multiple nonconditional variants, 44 to
conditional IRQ definitions needing review, and 126 remain unmatched. MP2
CA35, CM33, and CM0 headers are kept separate. Five Python tests cover matching,
IRQ parsing, conditional status, malformed input, limits, and snapshot digest.
This is a further T032 slice, not completion.

## SVD rule-index checkpoint

196 ST-authored Apache-2.0 SVD files were indexed from a pinned third-party
transport with per-file SHA-256 and transformation-feature counts. Reference
mapping yielded 1,641 single candidates, 47 core-specific variants, 37
multiple candidates, and 515 unresolved references. Four Python tests cover
feature extraction, malformed/DTD rejection, matching, and snapshot integrity.
The transport and exact-device applicability remain explicit limitations.

## Local STM32CubeMX database audit

The user's local `/home/rez0x61/STM32CubeMX/db` installation has package
database revision `DB.6.0.181`. Its Finder archive
`db/plugins/mcufinder/mcu/cube-finder-db.zip` is a 43,554,792-byte ZIP with
SHA-256 `9b5a52038e1dbbda98aaa36e370bc19c866db3b187af9add22147a3f2300e076`.
It contains an 87,060,480-byte SQLite database. Read-only, aggregate SQL
inspection passed ZIP CRC and SQLite `quick_check` integrity checks and
used a temporary extraction removed at process exit. It
found 17,948 commercial-part-number (`cpn`) rows and 14,736
reference-product (`rpn`) rows. Joining only the explicit STM32 MCU and MPU
product classes yielded 5,091 MCU and 275 MPU commercial-part-number rows;
44 of those 5,366 names still contain a wildcard `x`. The same join found
153 C5 and 37 H7RS commercial-part-number rows. Marketing status is stored
on reference-product rows, so its applicability to every commercial variant
requires validation rather than blind propagation. The schema also has flash,
RAM, core, die-ID, package, and security attributes.

The installed `help/software_license_agreement.pdf` has SHA-256
`6f977d32b83f2551c97dda96be939764eb8b17021076c0adefb2d8b`.
It identifies ST components under SLA0048 revision 5 and includes a
processing-unit restriction for the software package and derivatives. No
separate license for the Finder SQLite database was found in its directory or
ZIP. No source
rows, derived catalog, or database bytes were copied into the repository.
The aggregate audit establishes that CubeMX can help validate coverage, but
does not establish redistribution rights for Embedra's shipped host-side
catalog. T032 remains `IN_PROGRESS` pending explicit permission or another
licensed exact-part/lifecycle source.
