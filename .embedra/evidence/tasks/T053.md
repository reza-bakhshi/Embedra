# T053 Evidence — RP2350A/B and RP2354A/B providers: dual architecture, TrustZone, boot chain, OTP, QMI/XIP/PSRAM, package/memory differences, and 3 PIO blocks

## Status

`COMPLETE` on 2026-10-03. T053 implements comprehensive RP2350/RP2354 target provider data and architecture modeling under `targets.rp`:
- Silicon parts: RP2350A, RP2350B, RP2354A, and RP2354B.
- Package differentiation: RP2350A/RP2354A with 30 GPIOs (QFN-60) vs RP2350B/RP2354B with 48 GPIOs (QFN-80).
- Embedded memory differentiation: external QSPI/QMI flash on RP2350 vs 2 MiB stacked internal flash on RP2354.
- Dual architecture selection: supports dual ARM Cortex-M33 with TrustZone (`ARM:LE:32:v8-m`) and dual Hazard3 RV32IMAC RISC-V (`RISCV:LE:32:default` with compiler `gcc`).
- Strict RP-004 invariant: the inactive architecture is completely omitted from execution topology.
- TrustZone security domains: Secure vs Non-Secure domains modeled per architecture and core.
- Multi-stage secure boot chain: `Rp2350BootChain` modeling BootROM, IMAGE_DEF validation, security attributes, and stage transitions.
- OTP security memory: `Rp2350OtpMemory` modeling 8 KiB OTP (`0x40130000`, 2048 words), chip ID, boot flags, Secure Boot public key hashes (key slots 0-3), and rollback counter limits.
- QMI/XIP flash and PSRAM: QMI flash at `0x10000000` and external PSRAM window at `0x11000000`.
- Memory regions: 32 KiB Boot ROM, 520 KiB multi-bank SRAM (`0x20000000`), OTP (`0x40130000`), Peripherals (`0x40000000`), Atomic aliases (`0x50000000`).
- Hardware accelerators: SHA-256 (`rp2350.sha256`) and TRNG (`rp2350.trng`) modeled as fixed-function accelerator nodes.
- Both-core startup: Core 0 launches Core 1 via SIO FIFO (`rp2350.core0_launches_core1`).
- Three PIO blocks: `pio0` (`0x50200000`), `pio1` (`0x50300000`), and `pio2` (`0x50400000`), each with 4 state machines, 32-word instruction memory, 4-word FIFO depth, and dedicated IRQs.
- Vector tables: ARM Cortex-M33 (16 core exception vectors and 52 user IRQs, totaling 68 entries) and RISC-V MTVEC trap vectors.
- Pure/adapter boundary maintained: all models and providers stay pure under `targets.rp` without importing Ghidra APIs.
- All silicon support states remain `PLANNED` per RP-002 and STM-019.

## Scope and Invariants

- RP-004: Inactive architecture is never present in execution topology.
- TOPO-001..006: Topology contains 8 processor nodes: Core 0, Core 1, BootROM, PIO0, PIO1, PIO2, SHA-256, TRNG; 1 boot relationship; 5 communication links.
- Pure models in `io.github.rezabakhshi.embedra.targets.rp`: `Rp2350VectorTable`, `Rp2350OtpMemory`, `Rp2350BootChain`, `Rp2350TargetProvider`.
