# T089 Evidence — Build Independently Generated, Redistributable STM8 Fixtures and Oracles

## Status

`COMPLETE` on 2026-10-13. T089 builds independently generated, redistributable STM8
fixtures and official-tool oracles across raw BIN, Intel HEX, Motorola S-Record,
and ELF formats for 8 representative parts (STM8S003F3P6, STM8S103F3P6, STM8S208RBT6,
STM8L151C8T6, STM8L152R8T6, STM8AF5288TAY, STM8AL3188TA, and STM8T143AU) spanning all
four lines (STM8S, STM8L, STM8A, STM8T), alongside 6 malformed, truncated, wrong-checksum,
overlapping, and invalid-vector fixtures. All 38 fixtures are accompanied by
manifests and oracles satisfying `scripts/validate-fixture-provenance.sh` in
accordance with `Embedra-SpecKit.md` (T089, STM8-001, STM8-002, STM8-003, STM8-004,
STM8-005, and Section 12).

## 1. Deliverables

1. **Deterministic Fixture Generator**:
   - `scripts/generate-stm8-fixtures.py`:
     - Compiles authentic 128-byte vector tables (32 slots with opcode `0x82` `JPF`)
       and freestanding STM8 instructions (`SIM`, `LDW`, `NOP`, `JR`, `IRET`).
     - Emits bit-exact Intel HEX (Record types 00, 01, and 04 extended linear addressing
       for STM8S208 where flash extends to `0x027FFF`).
     - Emits Motorola S-Record (S0 header, S1 16-bit address records, S2 24-bit address
       records, S9 16-bit termination record).
     - Emits standard ELF32 big-endian executable files (`EM_NONE`, big-endian, entry `0x008080`,
       `.text` segment at `0x008000`).

2. **Representative Part Fixtures (32 Valid Fixtures)**:
   - Formats: `.bin`, `.hex`, `.s19`, `.elf` for each of:
     - `STM8S003F3P6` (8 KiB Flash, 1 KiB RAM, 128 B EEPROM)
     - `STM8S103F3P6` (8 KiB Flash, 1 KiB RAM, 640 B EEPROM)
     - `STM8S208RBT6` (128 KiB Flash, 6 KiB RAM, 2 KiB EEPROM, CAN)
     - `STM8L151C8T6` (64 KiB Flash, 4 KiB RAM, 2 KiB EEPROM)
     - `STM8L152R8T6` (64 KiB Flash, 4 KiB RAM, 2 KiB EEPROM, LCD)
     - `STM8AF5288TAY` (64 KiB Flash, 6 KiB RAM, 2 KiB EEPROM, CAN, LIN)
     - `STM8AL3188TA` (64 KiB Flash, 4 KiB RAM, 2 KiB EEPROM, LIN)
     - `STM8T143AU` (8 KiB Flash, 1 KiB RAM, 128 B EEPROM, ProxSense)

3. **Malformed Negative Fixtures (6 Fixtures)**:
   - `stm8s003_checksum.hex`: Corrupted checksum byte on Intel HEX data record.
   - `stm8s103_truncated.bin`: Truncated binary (64 bytes < 128-byte vector table).
   - `stm8l151_checksum.s19`: Corrupted Motorola S-Record checksum.
   - `stm8s208_overlapping.hex`: Conflicting overlapping physical addresses.
   - `stm8af_invalid_opcode.bin`: Vector slot 0 opcode `0x00` instead of `0x82`.
   - `stm8al_out_of_bounds_vector.bin`: Reset vector target `0x040000` outside flash bounds.

4. **Manifests and Oracles**:
   - 38 fixture manifests under `src/test/resources/fixtures/stm8/` conforming to
     `scripts/validate-fixture-provenance.sh`.
   - 14 oracle JSON snapshots under `src/test/resources/oracles/stm8/`.

5. **Automated Verification**:
   - Python unit test: `scripts/tests/test_stm8_fixtures.py` (6 tests).
   - Java pure unit test: `src/test/java/io/github/rezabakhshi/embedra/targets/stm8/Stm8FixtureTest.java` (3 tests).
