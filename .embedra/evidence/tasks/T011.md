## Implementation

- `EspImageDetector` returns `NO_MATCH`, `MATCH`, or `MALFORMED` without using
  filenames.
- `EspImageParser` reads the 24-byte common/extended header and each little-
  endian segment through the shared bounded reader.
- Structural validation enforces 1-16 segments, less than 16 MiB per segment,
  four-byte stored lengths, checked 32-bit target ranges, no overlap, explicit
  chip expectation when requested, even entry alignment and segment
  containment, footer bounds, XOR checksum seed `0xEF`, optional SHA-256, exact
  EOF, configured input/allocation/object limits, and cancellation.
- Immutable models retain encoded addresses and exact source ranges. Mutable
  arrays are cloned on construction and access; segment collections use
  immutable copies.
- Stable ESP diagnostic IDs distinguish magic/header, chip, segment, overlap,
  checksum, digest, entry, and trailing-data failures.

Exact language alignment, executable-region validation, and memory permissions
are intentionally deferred to the T012/T013 target provider. Generic parsing
preserves chip identity and does not silently select a target.
