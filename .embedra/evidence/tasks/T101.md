# T101 Evidence — Real-Ghidra GUI & Headless Multi-Program Import Wiring for Nordic Semiconductor nRF

## Status

`COMPLETE` on 2026-10-14. T101 wires pure Nordic target plans into the Ghidra import pipeline supporting
raw BIN, Intel HEX, and ELF formats across both GUI and headless environments. The import pipeline
resolves composite multi-image layouts (MBR at `0x00000000`, SoftDevice at `0x00001000`, relocated application
at `0x00019000` for S112, `0x00026000` for S132, or `0x00027000` for S140, and UICR bootloader entry at `0x10001014`),
dual-core cross-program binding for nRF5340 (Application core and Network core linked via shared IPC channels),
and ARM TrustZone Secure / Non-Secure partitioning for nRF9160. Fail-closed validation strictly catches
corrupted vectors, truncated Intel HEX records, checksum mismatches, overlapping records, and truncated ELF
headers. Transactional mutations execute via `GhidraProgramTransaction` with complete rollback on cancellation
or failure, and 100% GUI and headless CLI parity is verified via `GhidraProgramEquivalenceAssertor` across
different locales and timezones in accordance with `Embedra-SpecKit.md` (T101, NRF-001 through NRF-010,
Section 8.3A, and Section 12).

## 1. Deliverables

1. **Ghidra Nordic Integration Components**:
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/nordic/NordicMappingException.java`:
     - Checked exception carrying `DiagnosticCode` for Ghidra mapping failures.
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/nordic/NordicImportReport.java`:
     - Immutable report record detailing import outcome, exact part, series, format, language ID,
       compiler spec, entry point, flash base, flash bytes, blocks created, and registers applied.
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/nordic/NordicInputDecoder.java`:
     - Multi-format validating input decoder:
       - RAW_BINARY: Enforces Cortex-M vector table requirements (initial SP in SRAM `0x20000000..0x2FFFFFFF`
         and odd Thumb reset vector).
       - INTEL_HEX: Enforces record checksums, line lengths, non-overlapping segments, SoftDevice/relocated
         application vector discovery, and UICR `BOOTLOADERADDR` extraction.
       - ELF: Validates 32-bit little-endian ARM ELF header, machine 40, program/section header bounds,
         and extracts PT_LOAD segments.
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/nordic/NordicFirmwareMapper.java`:
     - Transactional mapper executing via `GhidraProgramTransaction`:
       - Language validation (`ARM:LE:32:*`).
       - Initializes firmware segments and maps uninitialized regions (`RAM`, `FICR`, `UICR`,
         `PERIPHERALS_APB`, `PERIPHERALS_SECURE`, `CRYPTOCELL`, `NETWORK_FLASH`, `NETWORK_SRAM`).
       - Labels primary entry points (`Reset_Handler`, `Application_Reset_Handler`, `MBR_Reset_Handler`,
         `SoftDevice_Reset_Handler`, `Bootloader_Reset_Handler`).
       - Applies peripheral pack registers and comments from `NordicPeripheralPack`.
       - Records options under category `"Embedra Nordic Firmware"`.
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/nordic/NordicFirmwareImportService.java`:
     - High-level import service resolving catalog parts and peripheral packs:
       - Single firmware image import (`importFirmware`).
       - Dual-core nRF5340 cross-program pair import (`importDualCorePair`) with IPC channel annotations.
       - ARM TrustZone nRF9160 cross-program pair import (`importTrustZonePair`) with security domain annotations.
   - `src/main/java/io/github/rezabakhshi/embedra/ghidra/nordic/NordicFirmwareLoader.java`:
     - Ghidra loader entry point extending `AbstractLibrarySupportLoader`:
       - Declares loader name `"Embedra Nordic nRF Firmware"`.
       - Provides target silicon part option `Target Silicon Part (optional override)`.
       - Validates load specs and returns `ARM:LE:32:Cortex` with compiler `default`.
       - Guarantees 100% parity between GUI and headless CLI execution.

     - `testMalformedFixturesFailClosed`: Validates fail-closed rejection on all 5 malformed fixtures (`nrf52_invalid_vector.bin`,
       `nrf52_truncated.hex`, `nrf52_bad_checksum.hex`, `nrf52_overlapping.hex`, `nrf52_truncated_elf.elf`).
