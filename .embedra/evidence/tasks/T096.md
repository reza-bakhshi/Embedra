- **Series**: 5 (`nRF51`, `nRF52`, `nRF53`, `nRF54`, `nRF91`).
- **Exact Parts**: 21 (5 nRF51, 10 nRF52, 2 nRF53, 2 nRF54, 2 nRF91).
- **Mandatory Parts Audited**: `nRF51822-QFAA`, `nRF51822-QFAC`, `nRF51802-QFAA`,
  `nRF52832-QFAA`, `nRF52840-QIAA`, `nRF52810-QCAA`, `nRF52833-QIAA`,
  `nRF5340-QKAA`, `nRF54L15`, `nRF54H20`, `nRF9160-SICA`.
- **Support State**: All 21 parts initialize as `PLANNED` per NRF-010.
- **Physical Memory Anchors**:
  - Code Flash: `0x00000000`
  - SRAM: `0x20000000`
  - FICR: `0x10000000` (nRF51/nRF52) / `0x00FF0000` (nRF53/nRF91/nRF54)
  - UICR: `0x10001000` (nRF51/nRF52) / `0x00FF8000` (nRF53/nRF91/nRF54)
  - Peripherals APB/AHB: `0x40000000` (Non-Secure) / `0x50000000` (Secure/GPIO)
  - CryptoCell: `0x5002A000` (CC310 on nRF52840), `0x50840000` (CC312 on nRF5340 / nRF9160).
- **Matching Policy**: Exact part string match only; wildcards and family prefixes rejected.
