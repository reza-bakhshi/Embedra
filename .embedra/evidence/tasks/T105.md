# T105 Evidence — Build Independently Generated, Redistributable Atmel / Microchip Fixtures and Oracles

## Status

`COMPLETE` on 2026-10-14. T105 builds independently generated, redistributable synthetic
Atmel / Microchip firmware fixtures and official-tool oracles covering raw BIN, Intel HEX,
and ELF formats for representative parts across 8-bit AVR (`ATmega328P`, `ATmega2560`, `ATtiny85`)
and 32-bit ARM SAM (`SAMD21G18A`, `SAME70Q21`); implements bootloader sections (Optiboot at `0x7E00`
on `ATmega328P` and SAM-BA ROM at `0x00800000` on `SAME70Q21`); implements multi-stage composite layouts
(application at `0x0000` + Optiboot bootloader at `0x7E00`); validates vector table stride invariants
(2-byte `RJMP` for $\le$ 8 KiB Flash vs 4-byte `JMP` for > 8 KiB Flash and Cortex-M Thumb vectors);
and authors 7 negative malformed fixtures covering corrupted checksums, truncated records, overlapping
records, invalid vector opcodes, initial stack pointers outside physical SRAM, truncated vector tables,
and truncated ELF headers. All 21 fixtures are accompanied by companion manifests and oracles satisfying
`scripts/validate-fixture-provenance.sh` in accordance with `Embedra-SpecKit.md`
(T105, ATMEL-001, ATMEL-002, ATMEL-003, ATMEL-004, ATMEL-005, ATMEL-006, ATMEL-007, and Section 12).

## 1. Deliverables

1. **Deterministic Fixture Generator**:
   - `scripts/generate-atmel-fixtures.py`:
     - Synthesizes 4-byte `JMP` vector tables for `ATmega328P` (26 vectors) and `ATmega2560` (57 vectors).
     - Synthesizes 2-byte `RJMP` vector tables for `ATtiny85` (15 vectors).
     - Synthesizes Cortex-M vector tables with valid SRAM initial SP and odd Thumb reset vectors
       for `SAMD21G18A` and `SAME70Q21`.
     - Synthesizes 512-byte Optiboot bootloader image at `0x7E00` with STK500v1 UART protocol stubs.
     - Synthesizes SAM-BA boot ROM image at `0x00800000` for `SAME70Q21`.
     - Synthesizes composite Intel HEX (`atmega328p_composite.hex`) combining application and Optiboot.
     - Emits standard 32-bit Little-Endian AVR ELF32 executables (`EM_AVR = 83`).
     - Emits standard 32-bit Little-Endian ARM ELF32 executables (`EM_ARM = 40`).
     - Emits Intel HEX records with valid 2-byte checksums, type 00 data, and type 04 extended addressing.

2. **Valid Representative Part Fixtures (14 Fixtures)**:
   - Bare-metal application images (BIN, HEX, ELF):
     - `atmega328p_app.bin`, `atmega328p_app.hex`, `atmega328p_app.elf` (AVR RISC, 4-byte `JMP`, SP `0x08FF`)
     - `atmega2560_app.bin`, `atmega2560_app.hex`, `atmega2560_app.elf` (AVR RISC, 256KB Flash, 57 vectors)
     - `attiny85_app.bin`, `attiny85_app.hex`, `attiny85_app.elf` (AVR RISC, 2-byte `RJMP`, SP `0x025F`)
     - `samd21g18a_app.bin`, `samd21g18a_app.hex`, `samd21g18a_app.elf` (Cortex-M0+, Flash `0x00000000`, SP `0x20008000`)
     - `same70q21_app.bin`, `same70q21_app.hex`, `same70q21_app.elf` (Cortex-M7, Flash `0x00400000`, SP `0x20460000`)
   - Bootloader and composite layouts:
     - `atmega328p_optiboot.bin`, `atmega328p_optiboot.hex`, `atmega328p_optiboot.elf` (512-byte Optiboot at `0x7E00`)
     - `atmega328p_composite.hex` (App at `0x0000` + Optiboot at `0x7E00`)
     - `same70q21_samba.bin`, `same70q21_samba.hex` (SAM-BA ROM at `0x00800000`)

3. **Malformed Negative Fixtures (7 Fixtures under `atmel/malformed/`)**:
   - `atmel_bad_checksum.hex`: Intel HEX record with corrupted checksum byte (`HEX_CHECKSUM_MISMATCH`).
   - `atmel_truncated.hex`: Intel HEX truncated in mid-record (`HEX_UNEXPECTED_EOF`).
   - `atmel_overlapping.hex`: Conflicting duplicate records at `0x00000000` (`MEMORY_OVERLAP_CONFLICT`).
   - `attiny85_invalid_vector.bin`: Vector table containing invalid/illegal instruction opcodes (`INVALID_AVR_VECTOR_TABLE`).
   - `samd21_bad_sp.bin`: Initial SP `0xFFFFFFFC` outside SRAM aperture (`INVALID_INITIAL_SP`).
   - `same70_truncated.bin`: Binary length 32 bytes smaller than Cortex-M vector table (`BINARY_TRUNCATED_VECTOR_TABLE`).
   - `atmega328p_truncated_elf.elf`: ELF file truncated before section headers (`ELF_TRUNCATED_HEADER`).
