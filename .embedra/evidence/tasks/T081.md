# T081 Evidence — Build Redistributable ESP Full-Flash Fixtures and Official-Tool Oracles

## Status

`COMPLETE` on 2026-10-13. T081 generates independently generated, redistributable
full-flash goldens and official-tool oracles for each of the 14 cataloged ESP32-branded
series (`ESP32`, `ESP32-S2`, `ESP32-S3`, `ESP32-S31`, `ESP32-P4`, `ESP32-C2`, `ESP32-C3`,
`ESP32-C5`, `ESP32-C6`, `ESP32-C61`, `ESP32-E22`, `ESP32-H2`, `ESP32-H21`, `ESP32-H4`).
Coverage encompasses bootloader plus factory/OTA layouts, custom partition table offsets,
erased application slots, relevant embedded-flash variants, and explicit offset manifests.
Negative/malformed fixtures cover wrong chip IDs, truncated flash, erased slots, overlapping
partition table entries, invalid partition MD5 checksums, and misleading magic bytes. Missing
authoritative inputs strictly block unsupported series without substituting S3 samples.

## 1. Deliverables

1. **Automated Fixture Generator**:
   - `scripts/generate-esp-full-flash-fixtures.py`:
     - Uses authoritative ESP-IDF v6.0 partition table tool (`gen_esp32part.py`) and
       independently compiled minimal applications (`<target>-freestanding-minimal.bin`).
     - Respects series-specific bootloader offsets: `0x1000` for ESP32; `0x0000` for
       all other 13 series (`ESP32-S2`, `S3`, `S31`, `P4`, `C2`, `C3`, `C5`, `C6`, `C61`,
       `E22`, `H2`, `H21`, `H4`).
     - Deterministically builds binary images, companion `.bin.manifest.json` files,
       and official oracle `.expectations.json` / `.esp-idf.csv` / `.esp-idf.txt` outputs.
     - Preserves existing pre-T081 ESP32-S3 test manifests and goldens without regression.

2. **Per-Series Fixture Matrix**:
   - For all 14 cataloged series:
     - `default-factory.bin` & `default-factory.bin.manifest.json`: Standard layout with
       bootloader at target offset, partition table at `0x8000`, factory app at `0x10000`,
       NVS at `0x9000`, PHY at `0xF000`, SPIFFS storage at `0x30000`.
     - `custom-offset-misleading-magic.bin` & manifest: Non-default table offset (`0x10000`),
       factory app at `0x20000`, false partition table magic at `0x6000` and `0x8000`,
       and false app magic at `0x7000`.
     - `ota-custom-encrypted.bin` & manifest: OTA data at `0xD000`, OTA0/OTA1 slots at
       `0x10000` and `0x30000`, encrypted assets custom partition at `0x50000`.
     - `invalid-partition-md5.bin` & manifest: Standard layout with a single mutated byte
       in the partition table MD5 checksum trailer.
   - For promoted series:
     - `malformed-wrong-chip.bin` & manifest: Mutated application chip ID to trigger
       `ESP_CHIP_ID_MISMATCH` rejection.
     - `malformed-truncated.bin` & manifest: Truncated flash inside factory application space.
     - `erased-slot.bin` & manifest: Fully erased (`0xFF`) factory slot.
     - `malformed-overlapping-partitions.bin` & manifest: Table with overlapping partition
       ranges (`0x10000..0x40000` overlapping storage at `0x30000..0x40000`).

3. **Official-Tool Oracles**:
   - `src/test/resources/oracles/<target>/full-flash/`:
     - `default-factory.esp-idf.csv`: Official CSV decoded by `gen_esp32part.py`.
     - `custom-offset-misleading-magic.esp-idf.csv`: Official decoded CSV for custom offset.
     - `ota-custom-encrypted.esp-idf.csv`: Official decoded CSV for OTA layout.
     - `invalid-partition-md5.esp-idf.txt`: Official `gen_esp32part.py` error oracle.
     - `malformed-overlapping-partitions.esp-idf.txt`: Official overlap detection oracle.
     - Companion `.expectations.json` for every fixture.

4. **Automated Verification**:
   - `scripts/tests/test_esp_full_flash_fixtures.py`:
     - Validates that all 14 series have complete, redistributable fixture sets.
     - Confirms bootloader offset invariants (`0x1000` for ESP32 with `0x0000..0x1000` erased;
       `0x0000` for all other series).
     - Confirms partition table magic and SHA-256 integrity against manifests.
