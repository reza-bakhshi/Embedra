## Fixture matrix

- `default-factory.bin`: valid MD5 table at `0x8000`, factory application and
  representative NVS/PHY/SPIFFS data partitions.
- `custom-offset-misleading-magic.bin`: valid table at `0x10000`, invalid
  partition-entry magic at `0x6000` and `0x8000`, and misleading application
  magic at `0x7000`.
- `ota-custom-encrypted.bin`: OTA data, OTA0/OTA1 apps, and encrypted custom
  type `0x40`, subtype `0x7f`.
- `invalid-partition-md5.bin`: exact default flash except for one flipped MD5
  byte at flash offset `0x8090`.

All images are 524,288 bytes. Every binary has an adjacent provenance manifest
and machine-readable expectation. Valid tables have retained official decoded
CSV output; the invalid table has retained official rejection output.

## Limitations and next action

Data-region markers are deterministic extraction payloads, not valid NVS,
OTA-state, PHY, SPIFFS, or encrypted ciphertext. T018 implements no discovery,
parser, loader, or support claim.

tests and keep flash offsets distinct from CPU addresses. Do not begin T020.
