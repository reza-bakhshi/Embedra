# T102 Evidence — Nordic SDK & Zephyr Signatures, BLE Identifiers & Analyzer Enrichment

## Status

`COMPLETE` on 2026-10-14. T102 implements nRF5 SDK and nRF Connect SDK (Zephyr-based) crypto/networking signatures,
Bluetooth Low Energy (BLE) stack identifiers, and CTF/string/lead enrichment pipelines for Nordic Semiconductor
nRF microcontrollers in accordance with `Embedra-SpecKit.md` (T102, NRF-005, NRF-009, NRF-010, Section 8.3A, and Section 12).

## 1. Deliverables

1. **Pure Nordic Signature Engine**:
   - `NordicLibrarySignature.java`: Masked byte-pattern signature model with defensive cloning, fully specified
     mask reporting, and SHA-256 provenance tracking.
   - `NordicFunctionBytes.java`: Address and function machine code container.
   - `NordicSignatureContext.java`: Exact part, series, compiler, optimization, and scanned function context.
   - `NordicSignatureMatch.java` & `NordicSignatureNonMatch.java`: Match/non-match audit records.
   - `NordicSignatureMatchReport.java`: Aggregated signature scan report.
   - `NordicSignaturePack.java`: Curated built-in signature pack containing:
     - nRF5 SDK BLE routines: `sd_ble_gap_adv_start`, `sd_ble_gatts_service_add`.
     - nRF5 SDK drivers & runtime: `nrfx_gpiote_init`, `app_timer_create`, `nrf_crypto_init`.
     - nRF Connect SDK (Zephyr) routines: `bt_enable`, `bt_le_adv_start`, `psa_crypto_init`, `z_cstart`.
     - SoftDevice dispatcher: `sd_nvic_critical_region_enter`.
   - `NordicSignatureMatcher.java`: Pure bounded matcher enforcing NRF-009/NRF-010 evidence gating under
     `ParserLimits` and `CancellationToken`.

2. **CTF, String & Security Lead Pipeline**:
   - `NordicCtfEnrichmentContext.java`: Memory bytes, functions, and symbols container.
   - `NordicCtfEnrichmentReport.java`: Deterministic analysis results.
   - `NordicCtfEnrichmentAnalyzer.java`: Pure pipeline executing signature matching, multi-encoding string
     scanning, stack string recovery (ARM Thumb), CTF entity discovery (flags, URLs, credentials), and 32-bit
     command table discovery with Thumb-bit awareness.

3. **Ghidra Analyzer Pipeline**:
   - `EmbedraNordicSignatureAnalyzer.java`: Ghidra `AbstractAnalyzer` registering as
     `"Embedra Nordic SDK & BLE Signatures"` under `FUNCTION_ANALYSIS.after()`, labeling matched functions,
     setting PLATE/EOL comments, and tagging BLE/Crypto bookmarks.

4. **Automated Unit & Integration Tests**:
   - `NordicLibrarySignatureTest.java`: Pattern masking, defensive copy immutability, validation constraints.
   - `NordicSignatureMatcherTest.java`: nRF5 SDK and Zephyr matches, evidence gating, resource limits, and cancellation.
   - `NordicCtfEnrichmentAnalyzerTest.java`: Full pipeline test verifying signatures, static string extraction,
     flag/URL CTF discovery on Nordic code.
   - `EmbedraNordicSignatureAnalyzerTest.java`: Ghidra analyzer metadata, priority, enablement, and null safety.
