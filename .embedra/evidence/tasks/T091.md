# T091 Evidence — Implement STM8 Interrupt Vector Table Parsing, Scoring, Entry-Point Resolution & Label Generation

## Status

`COMPLETE` on 2026-10-13. T091 implements STM8 interrupt vector table parsing, heuristic
scoring, application entry-point resolution, and handler label generation for the 32-vector
table anchored at `0x008000` (4-byte entries starting with opcode `0x82` `JPF` followed by
big-endian 24-bit jump target) with confidence gating under shared `ParserLimits` and
`CancellationToken` in accordance with `Embedra-SpecKit.md` (T091, STM8-004, STM8-005,
Section 8.2A, and Section 12).

## 1. Deliverables

1. **Vector Slot Definitions & Handler Label Generation**:
   - `Stm8VectorSlot.java`: Enumeration of all 32 vector table slots (0 to 31) with canonical
     names, table offsets (`0x008000 + slot * 4`), descriptions, and family-specific handler
     label generators for STM8S (mainstream), STM8L (ultra-low-power), STM8A (automotive),
     and STM8T (touch-sensing).
   - Generates authoritative handler labels:
     - Universal slots 0–9: `Reset_Handler`, `TRAP_IRQHandler`, `TLI_IRQHandler`, `AWU_IRQHandler`,
       `CLK_IRQHandler`, `EXTI0_IRQHandler`–`EXTI4_IRQHandler`.
     - Family-differentiated peripheral slots 10–31: e.g. slot 10 maps to `CAN_RX_IRQHandler` on
       STM8S/AF, `AES_IRQHandler` on STM8L/AL, and `TOUCH_IRQHandler` on STM8T.

2. **Decoded Vector Entry & Table Models**:
   - `Stm8VectorEntry.java`: Immutable parsed entry model recording slot index, vector table address,
     opcode byte, 24-bit target address, opcode validity (`opcode == 0x82`), physical target validity
     (target within Flash boundaries and non-self-looping), handler label, description, and stub detection.
   - `Stm8VectorTable.java`: Decoded 32-entry table model anchored at `0x008000`, exposing lookup by
     slot index, lookup by handler label, valid entries filter, score summary, and confidence gating.

3. **Heuristic Scoring & Confidence Gating Engine**:
   - `Stm8VectorTableScore.java`: Immutable scoring model computing valid opcode count, valid target
     count, unique target count, opcode ratio, target ratio, and overall confidence (`Confidence.DERIVED`,
     `Confidence.HEURISTIC`, `Confidence.UNKNOWN`).
   - Gating invariants:
     - If slot 0 (RESET) is invalid or not opcode `0x82`, confidence is immediately gated to `UNKNOWN`.
     - High confidence (`DERIVED`) requires valid reset vector and >= 8 valid entries.
     - Medium/Low confidence (`HEURISTIC`) requires valid reset vector and 1–7 valid entries.

4. **Vector Table Parser & Discoverer**:
   - `Stm8VectorTableParser.java`: Pure bounded parser and discoverer:
     - `parse(...)`: Extracts and decodes the 32 vector entries from binary slices.
     - `parseAndValidate(...)`: Fails closed with `DiagnosticCode.STM8_VECTOR_TABLE_INVALID` on
       malformed tables or invalid reset vectors.
     - `discover(...)`: Discovers candidate vector tables in raw images or memory dumps containing
       offset `0x008000`.
     - Fails closed on truncated inputs (< 128 bytes) with `DiagnosticCode.STM8_VECTOR_TABLE_TRUNCATED`.
     - Enforces cooperative cancellation with `CancellationToken` and size bounds with `ParserLimits`.

5. **Diagnostic Codes**:
   - Added stable codes to `DiagnosticCode.java`: `STM8_VECTOR_TABLE_INVALID`, `STM8_VECTOR_TABLE_TRUNCATED`.

6. **Unit Test Suite**:
   - `Stm8VectorTableTest.java`: 7 automated unit tests validating:
     - Vector parsing across all 8 representative parts (`STM8S003F3P6`, `STM8S103F3P6`,
       `STM8S208RBT6`, `STM8L151C8T6`, `STM8L152R8T6`, `STM8AF5288TAY`, `STM8AL3188TA`, `STM8T143AU`).
     - Reset vector resolution to `0x008080` and TRAP vector to `0x008090`.
     - Vector table discovery from full memory buffers.
     - Fail-closed truncation handling on `stm8s103_truncated.bin`.
     - Fail-closed invalid opcode handling on `stm8af_invalid_opcode.bin`.
     - Fail-closed out-of-bounds target handling on `stm8al_out_of_bounds_vector.bin`.
     - Cancellation token enforcement.
     - Family-specific handler label differentiation.
