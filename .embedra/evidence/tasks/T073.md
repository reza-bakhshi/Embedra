## 1. Verified Invariants and Assertions

The equivalence harness (`GhidraProgramEquivalenceAssertor`) asserts strict bit-for-bit parity between programs produced via GUI-equivalent loaders and headless execution pipelines under intentionally divergent locales (`tr-TR` Turkish vs `ja-JP` Japanese vs `en-US` English) and timezones (`Asia/Tehran` vs `Pacific/Auckland` vs `UTC`):

1. **Memory Blocks & Byte-Level Digests**:
   - Total memory block count and exact block names.
   - Start address and end address bounds for each block.
   - Permissions: Read (`isRead()`), Write (`isWrite()`), Execute (`isExecute()`), Volatile (`isVolatile()`), and Overlay (`isOverlay()`).
   - Initialization status (`isInitialized()`).
   - Bit-for-bit SHA-256 byte digest (`MessageDigest.getInstance("SHA-256")`) computed over all mapped bytes of initialized blocks.
2. **Symbol Table**:
   - Total symbol count.
   - Symbol names, symbol types (`SymbolType`), and target address mappings.
   - Symbol namespaces and primary symbol status flags (`isPrimary()`).
3. **Entry Points**:
   - Exact count and identical address set for all program entry points (`program.getSymbolTable().getEntryPointIterator()`).
4. **Bookmarks**:
   - Bookmark category strings, addresses, bookmark types, and user comments (`program.getBookmarkManager().getBookmarksIterator()`).
5. **Program Options & Properties**:
   - Property keys and values under program option maps.
   - Per specification contract, host-dependent non-deterministic fields (`Program Information -> Date Created`, `Info.Date Created`) and test program display names ("GUI import" vs "Headless import") are excluded from equality checks.
6. **Canonical JSON Reports**:
   - Parity of normalized canonical JSON reports (`canonicalReportJson`), confirming stable structural diagnostics free of host filesystem paths and wall-clock timestamps.
7. **Workspace Snapshots**:
   - Normalized `WorkspaceSnapshot` parity across imports, verifying block topologies, memory addresses, permissions, and symbol models.
