## Implementation

- Pinned JUnit 6.1.3, JaCoCo 0.8.15, and Checkstyle 14.1.0.
- Added JUnit Platform execution with deterministic locale, timezone, encoding, and single-fork settings.
- Enabled Java compiler `-Xlint:all` with warnings treated as errors.
- Added Checkstyle rules and zero-warning enforcement.
- Added a local formatting verifier for UTF-8, LF endings, final newlines, tabs, and trailing whitespace.
- Added JaCoCo XML/CSV/HTML reports and a 90% branch-coverage rule scoped to future `io.github.rezabakhshi.embedra.core.*` classes.
- Configured stable archive ordering and timestamps.
- Added dependency locking and generated `gradle.lockfile`.
- Added a two-clean-build acceptance script that compares ZIP bytes/digests and exact contents.
- Kept build configuration, scripts, locks, continuity records, and the local Ghidra distribution out of the extension ZIP.
- Added ADR 0001 and build-only third-party license/provenance notices.

## Defects Found and Resolved

- The first task-name matcher assumed Gradle task descriptions; it was corrected to accept an exact task name with or without a description.
- Exact package validation rejected development-only Gradle files and an empty source ZIP. Development files are now excluded, and the source ZIP is omitted only while no production Java source exists.
- An intermediate expected-entry edit left an unterminated shell string. `sh -n` retained the failure and the script was corrected before acceptance.
