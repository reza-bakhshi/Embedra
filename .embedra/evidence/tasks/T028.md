# T028 Evidence — Original ESP32 and ESP32-S2 Support

## Status

`COMPLETE` on 2026-09-24. T029 is next.

## Scope and requirements

- Requirements: ESP-001 through ESP-005, ESP-017 through ESP-020, TOPO-001
  through TOPO-006, TEST-001, TEST-005, TEST-007, and specification T028.
- Inputs: ESP-IDF v6.0 revision
  `662a3be354759d9487bf4b1a629fadb766cb1800`, Espressif SVD revision
  `be20aa12560889d6125d144cdb48cf615ac17628`, esptool 5.4.0, and Espressif
  Xtensa toolchain `esp-15.2.0_20251204`.

## Test-first evidence

`Esp32AndS2TargetProviderTest` and `Esp32AndS2EnrichmentPackTest` were added
before implementation. Their first run failed compilation with seven missing
symbols for the two providers and target-neutral pack loader. The retained
tests cover exact chip-ID resolution, memory boundaries, independent topology,
and all three pack kinds for each target.

## Implementation

- Added reproducible, redistributable 416-byte application fixtures for ESP32
  chip ID 0 and ESP32-S2 chip ID 2 with pinned esptool and ELF oracles.
- Added providers with target-owned ESP-IDF memory maps. ESP32 records two
  symmetric LX6 application cores sharing the image; ESP32-S2 records one LX7
  application core. Both select Ghidra's built-in `Xtensa:LE:32:default`.
- Added independent ROM, peripheral-header, and SVD packs. ESP32 contains 1,997
  ROM symbols, 52 peripheral windows/1,418 header registers, and 46 SVD
  peripherals/2,613 registers. ESP32-S2 contains 1,014 ROM symbols, 53
  windows/1,286 header registers, and 43 SVD peripherals/3,514 registers.
- Corrected deterministic SVD array expansion to honor CMSIS `dimIndex` and
  regenerated the ESP32-S3 SVD pack with unchanged semantic counts.
- Generalized target pack loading and safe Ghidra application while preserving
  the existing ESP32-S3 entry points. The application loader resolves the
  validated chip ID, rejects provider-incompatible ranges, selects the correct
  language, and applies only the matching pack set when explicitly requested.
- Added raw and enriched real-Ghidra imports for both new targets, documentation,
  ADR 0023, provenance checks, and exact extension archive entries.

## Verification

- Focused red run: expected compilation failure with seven missing symbols.
- Focused provider, fixture, and pack tests passed after implementation.
- Real-Ghidra raw import and explicit target-matched enrichment tests passed for
  both ESP32 and ESP32-S2.
- Complete `check` passed: 162 unit tests, 55 real-Ghidra integration tests,
  and 4 Python generator tests, with no failures or skips.
- The full quality script ran two uncached clean builds with all 20 actions,
  verified fixture provenance and exact package contents, and produced a
  byte-identical 1,413,370-byte extension ZIP with SHA-256
  `288bad7a1ea4334c46bbfdf44eebc18576bfd50348d8d33958329d9be99bca0d`.

## Support boundary and limitations

Support is for generic image chip IDs 0 and 2. Exact silicon/package revisions,
ULP firmware, full-flash layouts for these targets, and real-hardware behavior
remain unverified. No ESP32-C3 or T029 implementation was started.
