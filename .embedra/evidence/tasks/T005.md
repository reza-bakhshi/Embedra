## Implementation

- Added a deterministic JSON writer that sorts string map keys, preserves list order, escapes JSON strings, emits integral numbers, and rejects sets, floating-point numbers, non-string keys, and unsupported objects.
- Added canonical report schema v1 containing build/input/component identity, validations and evidence, source-target mappings, applied symbols/types with provenance, metadata, optional topology, findings, diagnostics, and fixed reproducibility settings. Host paths and timestamps are absent.
- Added a complete deterministic projection of the T004 execution-topology graph, including processors and language/compiler/ISA identity, security domains, reset entries, address spaces, shared memory/aliases, boot relationships, communication links, processor groups, evidence, and program strategy.
- Added exact-device catalog snapshots with source revision/license/provenance and mandatory per-capability `PLANNED`, `EXPERIMENTAL`, `VERIFIED`, or `UNSUPPORTED` states. Deterministic diffs report added, removed, and changed exact IDs without inferred family verification.
- Added closed JSON Schema 2020-12 documents with stable URN IDs and packaged them as JAR resources.
- Added a snapshot assertion helper that refuses missing or changed oracles and never writes test resources.
- Documented the contracts in README, architecture documentation, and ADR 0004.
