# T065 Evidence — Vendor ROM API, Hardware Crypto Peripheral, Secure Element, Secure Boot/Flash Encryption, RNG, Call-Graph, and Cross-Program Detection

## Status

`COMPLETE` on 2026-10-10. T065 implements complete detection of vendor ROM cryptographic routines, memory-mapped hardware crypto accelerator registers, external secure element bus interfaces, eFuse/OTP key ladder configuration, secure boot, flash encryption, hardware random number generators (TRNG), call-graph resolution, and cross-program crypto data flow with per-device evidence (AN-010, AN-013, AN-014):

- Hardware Crypto Domain Models & Engines (`analyzers.crypto.hardware`):
  - `HardwareCryptoPlatform`: Enum representing concrete target silicon platforms (`ESP32`, `ESP32_S2`, `ESP32_S3`, `ESP32_C3`, `ESP32_C6`, `ESP32_H2`, `STM32_F4`, `STM32_F7`, `STM32_H7`, `STM32_L4`, `STM32_L5`, `STM32_U5`, `STM32_WB`, `RP2040`, `RP2350`, `GENERIC`).
  - `HardwareCryptoFeature`: Functional taxonomy covering `SYMMETRIC_ACCELERATOR`, `HASH_ACCELERATOR`, `ASYMMETRIC_ACCELERATOR`, `DIGITAL_SIGNATURE`, `HMAC_PERIPHERAL`, `TRNG_PERIPHERAL`, `EFUSE_OTP_KEY_LADDER`, `FLASH_ENCRYPTION_ENGINE`, `SECURE_BOOT_ENGINE`, `SECURE_ELEMENT_BUS`, `VENDOR_ROM_API`.
  - `HardwarePeripheralRegister`: Immutable specification model defining register ID, peripheral name, physical address, width, algorithm, trigger semantics, mode maps, and descriptions.
  - `VendorRomCryptoRoutine`: Models ROM routines with exact entrypoint addresses, RP2040 2-character lookup codes (e.g. `'RE'`, `'RP'`), and parameter documentation.
  - `SecureElementDefinition`: Models hardware secure elements (Microchip ATECC608A/B, Infineon OPTIGA Trust M, NXP EdgeLock SE050) with default 7-bit I2C addresses and supported cryptographic primitives.
  - `HardwareMemoryAccess`: Models memory loads and stores with statically resolved constant values.
  - `HardwareCallSite`: Models function call sites with target addresses, symbols, and constant register parameters.
  - `CrossProgramCryptoReference`: Models cross-program/core shared buffers, mailboxes, and key handoffs (`KEY_BLOB_HANDOFF`, `SECURE_IPC`).
  - `HardwareCryptoCatalog`: Authoritative built-in database indexing registers, ROM routines, and secure elements across ESP32, STM32, and RP2040/RP2350.
  - `HardwareCryptoAnalyzer`: Pure engine evaluating accesses, calls, and cross-program references under `ParserLimits` and `CancellationToken`. Corroborates MMIO writes against mode registers (AN-013: peripheral register access is a lead until the operation, mode, and data flow are supported by evidence).
