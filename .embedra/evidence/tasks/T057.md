# T057 Evidence — Endpoint, credential, certificate/key, token, UUID, and customizable flag scanners

## Status

`COMPLETE` on 2026-10-04. T057 implements bounded endpoint, credential, certificate, UUID, encoded blob, and customizable CTF flag recovery across memory blocks and extracted strings (AN-002, AN-006, AN-008):
- Pure CTF Entity Scanner (`analyzers.ctf`):
  - Pure pattern and entity scanner (`CtfEntityScanner`, `CtfEntity`, `CtfEntityCategory`, `CtfEntityType`, `CtfSeverity`, `CtfScanOptions`, `CtfFindingsReport`).
  - Scans across extracted static strings (`ExtractedString`), recovered stack strings (`RecoveredStackString`), and raw memory blocks under `ParserLimits` and `CancellationToken`.
  - Classifies findings into 6 core categories:
    - `ENDPOINT`: URLs (`http://`, `https://`, `ws://`, `wss://`, `coap://`, `mqtt://`, `ftp://`), valid IPv4 and IPv6 addresses, domain names with authoritative/internal TLDs, and structured MQTT topics (`tele/`, `stat/`, `cmnd/`, `sensor/`, `factory/`, `device/`, `#`, `+`).
    - `CREDENTIAL`: Wi-Fi configurations (`ssid=...`, `password=...`, `psk=...`), AWS Access Key IDs (`AKIA[0-9A-Z]{16}`), GitHub personal access tokens (`ghp_...`, `github_pat_...`), Slack tokens (`xox[baprs]-...`), JSON Web Tokens (`ey...`), and OpenSSH authorized keys.
    - `CERTIFICATE_KEY`: PEM-encoded certificates (`BEGIN CERTIFICATE`), private keys (`BEGIN RSA PRIVATE KEY`, `BEGIN PRIVATE KEY`), public keys (`BEGIN PUBLIC KEY`), and binary ASN.1 DER X.509 certificates (`0x30` sequence with explicit version tag `0xA0 0x03 0x02 0x01` and algorithm identifiers).
    - `UUID`: 128-bit BLE UUIDs (RFC 4122 format), 16-bit BLE assigned numbers (`0x180D`), and Ethernet/Wi-Fi/Bluetooth MAC addresses (`XX:XX:XX:XX:XX:XX` and `XX-XX-XX-XX-XX-XX`).
    - `ENCODED_BLOB`: Base64 encoded blobs (minimum length 24, character class entropy filtering, rejecting pure hex false positives) and continuous hexadecimal strings (minimum length 32).
    - `FLAG`: CTF flags matching default patterns (`flag\{...\}`, `CTF\{...\}`, `embedra\{...\}`) and configurable user-specified regex patterns via `CtfScanOptions`.
  - Secret redaction and export (`maskedValue()`, `CtfFindingsReport`):
    - Masks secret values (e.g. `AKIA****************`, `flag{***REDACTED***}`) to prevent sensitive credential leakage in console and log files (AN-008).
    - Structured export to JSON, Markdown tables, and SARIF 2.1.0 with secret redaction enabled by default.
- Ghidra Findings Annotation Applicator and Analyzer (`ghidra.ctf`):
  - Transactional applicator (`GhidraCtfApplicator`) executing in a single `GhidraProgramTransaction` (rolling back on error or cancellation).
  - Annotates discovered findings with `Embedra Findings: <CATEGORY>` bookmarks (e.g., `Embedra Findings: ENDPOINT`, `Embedra Findings: CREDENTIAL`, `Embedra Findings: FLAG`, `Embedra Findings: UUID`).
  - Annotates non-destructive EOL comments (`[Finding: <Type> (<Severity>)] <MaskedValue> - <Explanation>`).
  - Populates program options under `Embedra CTF Findings` (total findings count, counts by category, counts by severity).
  - Strictly preserves existing user labels, symbols, and bookmarks.
  - `EmbedraCtfAnalyzer` extends Ghidra's `AbstractAnalyzer` for automated memory block and stack-string CTF entity discovery.
  - Logs only aggregate counts to prevent sensitive credential exposure in log files (AN-008).

## Scope and Invariants

- Strictly bounded execution under `ParserLimits` (max objects, max input bytes) and `CancellationToken`.
- Do not alter or destroy existing user labels, symbols, or bookmarks.
- Pure analysis remains strictly separated from Ghidra Program DB mutation (`ArchitectureBoundaryTest` verified).
- Entities differentiate severity (`HIGH`, `MEDIUM`, `LOW`, `INFO`), confidence (`CONFIRMED`, `LIKELY`, `PLAUSIBLE`), and secret attribution.
- Zero secret leaking: unmasked credentials, tokens, private keys, and flags are never emitted in plain text in logs or reports (AN-008).
