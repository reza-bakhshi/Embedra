# T064 Evidence — Provenance-Checked, Compiler/Optimization/ISA-Aware Embedded Crypto Library Signatures

## Status

`COMPLETE` on 2026-10-10. T064 implements provenance-checked, compiler-, optimization-, and ISA-aware signatures for embedded cryptographic libraries, core algorithms, hardware wrappers, and inlined idioms across ARM Thumb, Xtensa, and RISC-V architectures with strict schema validation, deterministic SHA-256 integrity digests, bounded execution, and pure/adapter architectural separation (AN-010, AN-011, AN-012, AN-014):

- Pure Domain Models and Contracts (`analyzers.crypto.signatures`):
  - `CryptoLibrary`: Complete coverage of all 11 required libraries (`MBEDTLS`, `WOLFSSL`, `BEARSSL`, `TINYCRYPT`, `MONOCYPHER`, `MICRO_ECC`, `LIBTOMCRYPT`, `OPENSSL`, `ESP_IDF`, `STM32_HAL`, `PICO_SDK`, `CUSTOM`).
  - `CryptoIsa`: Target architecture filter (`ARM_THUMB`, `XTENSA`, `RISCV32`, `GENERIC`).
  - `CryptoCompiler`: Compiler toolchains (`GCC`, `CLANG`, `ARMCC`, `IAR`, `ANY`).
  - `CryptoOptimization`: Optimization levels (`O0`, `O1`, `O2`, `O3`, `Os`, `Oz`, `ANY`).
  - `CryptoArtifactRole`: Concrete artifact classification per AN-014 (`ALGORITHM_IMPLEMENTATION`, `WRAPPER`, `CALLER_USE_SITE`, `INLINED_IDIOM`, `CONSTANT_TABLE`, `KEY_SCHEDULE`, `IV_NONCE`, `PUBLIC_KEY`, `SECRET_KEY_CANDIDATE`, `CERTIFICATE`, `RANDOM_GENERATOR`, `PROTOCOL_ENCODING`).
  - `CryptoSignatureProvenance`: Record capturing library enum, library version, license name, source file path, and 64-hex SHA-256 source commit/tarball digest.
  - `CryptoLibrarySignature`: Byte-level signature model supporting masked matching (`0x00` wildcard, `0xFF` exact), enforcing minimum signature length (8 bytes), minimum significant unmasked bytes (4 bytes), and sub-millisecond masked chunk matching.
  - `CryptoSignaturePack`: Immutable container record with schema ID `urn:embedra:schema:crypto-signature-pack:1`, versioning, pack ID, list of signatures, and canonical SHA-256 integrity digest validation.
  - `CryptoSignatureMatchReport`: Immutable match report aggregating findings, matched signature IDs, evaluation time, bytes scanned, and deduplicated library hits.
- JSON Schema & Data Loading:
  - `schemas/crypto/crypto-signature-pack-v1.schema.json`: Closed JSON schema (`additionalProperties: false`) enforcing format rules, hex digest patterns, and artifact roles.
  - `CryptoSignatureJsonParser`: Bounded JSON parser respecting `ParserLimits` (max bytes, max nesting depth, max object count, wall time) and cooperative cancellation tokens.
  - `CryptoSignaturePackLoader`: Validates packs against the JSON schema, validates signatures, verifies canonical SHA-256 pack digests, and prevents corrupt or hostile pack loading.
  - `CryptoSignatureDatabase`: Embedded, pre-compiled signature catalog containing provenance-verified signatures across all 11 required libraries, core symmetric/asymmetric algorithms, hardware peripheral wrappers (ESP-IDF / STM32 HAL / Pico SDK), and inlined crypto idioms.
  - `CryptoLibrarySignatureMatcher`: High-performance execution engine evaluating memory chunks and function entrypoints against the signature catalog with ISA/compiler/optimization filters, cooperative cancellation, and execution budgets.
- Crypto Layer & Algorithm Expansions:
  - Expanded `CryptoAlgorithm` enum with AN-012 primitives: `CHACHA20_POLY1305`, `DIFFIE_HELLMAN`, `ECDSA`, `ECDH`, `X25519`, `SHA224`, `SHA384`, `POLY1305`, `HKDF`, `PBKDF2`, `DRBG_PRNG`, `TRNG`, `ASN1_KEY_CERT_PARSER`.
  - Added `CryptoEvidenceLayer.FUNCTION_SIGNATURE`.
  - Added `CryptoScanOptions.scanSignatures` flag (default `true`).
  - Updated `CryptoAnalysisPipeline` to fuse signature detections with constant tables, entropy blocks, public keys, and string hits.
  - Added diagnostics: `CRYPTO_SIGNATURE_INVALID`, `CRYPTO_SIGNATURE_PACK_INVALID`, `CRYPTO_SIGNATURE_INTEGRITY_MISMATCH`.
- Ghidra Application & Integration:
  - `GhidraCryptoApplicator`: Enriched bookmark formatting and comment generation to display library name, version, and artifact role (e.g., `Embedra Crypto: AES (mbedtls 3.6.0 [ALGORITHM_IMPLEMENTATION])`).
  - `EmbedraCryptoIntegrationTest`: End-to-end Ghidra integration verified on live program databases.
- Verification & Boundary Guarantees:
  - `CryptoLibrarySignatureTest`, `CryptoSignaturePackLoaderTest`, `CryptoSignatureDatabaseTest`, `CryptoLibrarySignatureMatcherTest`, `AdversarialCryptoSignatureTest`: 100% pass rate covering schema validity, integrity checks, ReDoS/hang defense, allocation limits, and boundary cases.
  - `ArchitectureBoundaryTest`: Confirmed zero Ghidra imports in `io.github.rezabakhshi.embedra.analyzers.crypto.*`.
