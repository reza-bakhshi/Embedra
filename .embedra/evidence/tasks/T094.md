# T094 Evidence — STM8 SPL & Compiler Runtime Signatures & Analyzer Enrichment

## Status

`COMPLETE` on 2026-10-13. T094 implements Standard Peripheral Library (SPL) and open-source compiler
runtime (SDCC, Cosmic) signatures, as well as 8-bit / 16-bit / 24-bit pointer-aware CTF and security lead
enrichment pipelines for STMicroelectronics STM8 microcontrollers in accordance with `Embedra-SpecKit.md`
(T094, STM8-005, STM8-009, Section 8.2A, and Section 12).

## 1. Deliverables

1. **Pure STM8 Signature Engine**:
   - `Stm8LibrarySignature.java`: Masked byte-pattern signature model with defensive cloning, fully specified
     mask reporting, and SHA-256 provenance tracking.
   - `Stm8FunctionBytes.java`: Address and function machine code container.
   - `Stm8SignatureContext.java`: Exact part, family, compiler, optimization, and scanned function context.
   - `Stm8SignatureMatch.java` & `Stm8SignatureNonMatch.java`: Match/non-match audit records.
   - `Stm8SignatureMatchReport.java`: Aggregated signature scan report.
   - `Stm8SignaturePack.java`: Curated built-in signature pack containing:
     - SPL routines: `GPIO_Init`, `CLK_DeInit`, `UART1_Init`, `TIM1_Cmd`, `SPI_Init`.
     - SDCC compiler runtimes: `__divsint`, `__mullong`, `__mulint`.
     - Cosmic compiler runtimes: `_switch`, `_i_div`, `_l_mul`.
   - `Stm8SignatureMatcher.java`: Pure bounded matcher enforcing STM8-009 evidence gating (rejects guesses
     when compiler or family evidence is missing), bounded by `ParserLimits` and `CancellationToken`.

2. **Shared Analyzer Pipeline Integration**:
   - Extended `InstructionArch.java` with `STM8`.
   - Extended `StackInstruction.java` with STM8 factory method (`stm8(...)`).
   - Extended `StackStringRecoveryAnalyzer.java` to support STM8 stack frame instructions (`mov (offset, sp), #imm`,
     `ld`, `ldw`, `push`, `pushw`, `addw sp`, `subw sp`).
   - Extended `ComparisonLeadScanner.java` with STM8 call instructions (`call`, `callf`, `callr`), register tracking
     (`a`, `x`, `y`, `sp`, `xl`, `xh`, `yl`, `yh`), and conditional branch instructions (`jreq`, `jrne`, etc.).
   - Extended `CallSiteArgumentResolver.java` for STM8 calling convention register mappings.
   - Extended `EmbedraSecurityLeadAnalyzer.java` with STM8 architecture detection and pointer-width aware command table
     dereferencing (supporting 16-bit and 24-bit pointers without Thumb bit clearing).
   - Extended `EmbedraCtfAnalyzer.java`, `EmbedraStringAnalyzer.java`, and `EmbedraLoggingAnalyzer.java` with STM8 detection.
   - Created `Stm8CtfEnrichmentAnalyzer.java`, `Stm8CtfEnrichmentContext.java`, and `Stm8CtfEnrichmentReport.java`.
   - Created `EmbedraStm8SignatureAnalyzer.java`: Ghidra `AbstractAnalyzer` registering as
     `"Embedra STM8 SPL & Runtime Signatures"` under `FUNCTION_ANALYSIS.after()`.

3. **Automated Unit & Integration Tests**:
   - `Stm8LibrarySignatureTest.java`: Pattern masking, defensive copy immutability, validation constraints.
   - `Stm8SignatureMatcherTest.java`: SPL and runtime matches for SDCC and Cosmic, STM8-009 evidence gating,
     resource limits, and cancellation.
   - `Stm8CtfEnrichmentAnalyzerTest.java`: Full pipeline test verifying SPL signatures, static string extraction,
     flag/URL CTF entity discovery, and stack string recovery on STM8 code.
   - `EmbedraStm8SignatureAnalyzerTest.java`: Ghidra analyzer metadata, priority, enablement, and null safety.
