# T107 Evidence — Implement AVR & SAM Interrupt Vector Table Parsing, Scoring & Entry Resolution

## Status

`COMPLETE` on 2026-10-14. T107 implements AVR and SAM interrupt vector table parsing, scoring,
entry-point resolution, and handler label generation across 8-bit AVR microcontrollers
(classic megaAVR, classic tinyAVR, and modern AVR-Dx) and 32-bit ARM SAM microcontrollers (SAMD, SAME)
under shared `ParserLimits` and `CancellationToken`, strictly isolated from other families.
It dynamically adapts to part vector strides: 2-byte `RJMP` (Flash $\le$ 8 KiB, e.g. `ATtiny85`),
4-byte `JMP` (Flash > 8 KiB, e.g. `ATmega328P`, `ATmega2560`), and Cortex-M 32-bit initial SP
and Thumb vector tables for SAM parts; supports vector tables anchored at `0x00000000` or `BOOTSZ`
bootloader addresses (e.g. `0x7E00` Optiboot); generates canonical labels (`Reset_Handler`,
interrupt-specific vector symbols); detects stub and shared handlers; and evaluates vector table
confidence in accordance with `Embedra-SpecKit.md` (T107, ATMEL-004, ATMEL-006, Section 8.3B, and Section 12).

## 1. Deliverables

1. **Instruction & Slot Domain Model**:
   - `io.github.rezabakhshi.embedra.targets.atmel.vector.AtmelVectorInstructionType`:
     - Models instruction types: `RJMP`, `JMP`, `THUMB_VECTOR`, `INITIAL_SP`, `INVALID`.
   - `io.github.rezabakhshi.embedra.targets.atmel.vector.AtmelVectorSlot`:
     - Metadata model representing vector slot definitions (index, name, description).
     - Factory `slotsFor(AtmelPartRecord)` generating exact vector slot mappings for ATmega328P
       (26 vectors), ATmega2560 (57 vectors), ATtiny85 (15 vectors), SAMD21 (44 vectors),
       and SAME70 (85 vectors).

2. **Parsed Entry & Table Entities**:
   - `io.github.rezabakhshi.embedra.targets.atmel.vector.AtmelVectorEntry`:
     - Models parsed entry: slot, entryAddress, targetAddress, rawInstruction, instructionType,
       isValid, isStub, canonicalLabel.
   - `io.github.rezabakhshi.embedra.targets.atmel.vector.AtmelVectorTableScore`:
     - Evaluates opcode validity, target addresses, unique targets, reset vector validity,
       and computes confidence (`VERIFIED`, `DERIVED`, `HEURISTIC`, `UNKNOWN`).
   - `io.github.rezabakhshi.embedra.targets.atmel.vector.AtmelVectorTable`:
     - Immutable parsed table with query interface (`resetEntry()`, `isConfident()`, `entryCount()`).

3. **Pure Vector Table Parser**:
   - `io.github.rezabakhshi.embedra.targets.atmel.vector.AtmelVectorTableParser`:
     - Supports 2-byte `RJMP` relative offset decoding (`targetWord = pcWord + rel`).
     - Supports 4-byte `JMP` absolute address decoding (handling 24-bit extended addressing).
     - Supports ARM Cortex-M initial SP range checking and Thumb bit resolution.
     - Supports relocation to bootloader boundaries (`BOOTSZ` e.g. `0x7E00`).
     - Detects stub handlers sharing identical target addresses.
     - Enforces `ParserLimits` and `CancellationToken`.

4. **Automated Unit Tests**:
   - `src/test/java/io/github/rezabakhshi/embedra/targets/atmel/AtmelVectorTableParserTest.java`:
     - Validates 4-byte `JMP` vector table parsing on `atmega328p_app.bin`.
     - Validates 2-byte `RJMP` vector table parsing on `attiny85_app.bin`.
     - Validates 57-vector table parsing on `atmega2560_app.bin`.
     - Validates Cortex-M vector table on `samd21g18a_app.bin` and `same70q21_app.bin`.
     - Validates bootloader vector relocation on `atmega328p_optiboot.bin` at `0x7E00`.
     - Validates fail-closed handling on malformed fixtures (`attiny85_invalid_vector.bin`,
       `samd21_bad_sp.bin`, `same70_truncated.bin`).
     - Validates cancellation and limits.
